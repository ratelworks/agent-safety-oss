# 미해결 항목 정리 (2.4.0)

외부 리뷰·온톨로지 리뷰에서 남은 항목과 전수 점검에서 나온 것을 처리한다.

## 전수 점검

처음 점검은 입력을 못 맞춘 도구가 많아(69개 중 33개가 입력 거절만) 결과로 쓸 수 없었다. 도구별 입력 형식에서 필수 항목을 읽어 다시 돌렸다: 읽기 전용 61개 도구를 1,771회 호출 — 정상 1,387, 도구가 처리한 오류 응답 376(빈 초안 검토의 불합격 판정 192건 등), 입력 거절 8, 내부 오류 0. 정상 응답이 없던 11개 중 9개는 올바른 입력으로 따로 호출해 모두 정상(497회), 나머지 2개(문서 검토·부분 검토)는 빈 초안에 불합격을 돌려주는 것이 정상 동작이다. 쓰기 도구 18개와 외부 호출 도구 13개는 돌리지 않았다.

## 반영

- **근거 검증**: "제○조" 표기와 수록하지 않은 법령의 인용을 "환각"으로 판정하던 결함 수정("§36" 표기는 정상이었다). 그래프의 조문·별표 노드와 대조하고 `confirmed`/`not_found`/`unverifiable` 로 판정(`src/lib/citation-resolver.ts`). 본조 번호가 1번부터 빠짐없이 수록된 법령(7개)에서만 "없는 조문"을 단정한다. 나열·범위 인용은 적힌 조문을 모두 확인하고, 범위의 중간 조문과 항·호는 대조하지 않았음을 알린다. `unverifiable` 은 partial 이며 오류 표시를 붙이지 않는다. 응답에 확인 범위(`scope`)를 싣는다.
- **검토 전 연결**: 2.1.0 이후 채워 넣은 규율 연결 309쌍을 `unreviewed-links.json` 에 두고, 가이드 연결 조회·현장 브리핑이 표시한다. 검토를 마치면 목록에서 뺀다.
- **법령 판본**: 문서에 인용 조문의 수록 판본 표시. 판본 점검에 `--require-key`(인증키 없으면 실패), 주간 점검 워크플로 추가.
- **주의 표시**: 외부 전송·삭제 도구에 MCP annotations.
- **도구가 가리키는 대상**: 동작 78·입력 형식 92·산출물 종류를 어휘 색인에 선언(도구 이름에서 기계적으로 생성). 선언 누락 0.
- **브라우저 입력 폼**: 보조 버튼 4개 동작, 초안 복원이 자동 채움을 지우던 것 수정, marked 를 설치 패키지에서 제공.

## 하지 않은 것 (사유)

- **인용이 주장을 뒷받침하는지의 판단**: 규칙으로 판정할 수 없다. 확인 범위를 응답에 밝히는 데 그쳤다.
- **검토 전 연결의 항목별 검토**(법령 근거 79건, 규율 309쌍): 안전 법령 지식이 필요한 판단이라 표시만 했다.
- **용어 뜻 설명**: 속성 114종의 의미를 추정해 적으면 공개 온톨로지에 틀린 정의가 들어갈 수 있다.
- **식별자 주소 호스팅**: 도메인 설정과 호스팅이 필요하다.
- **평가 지표 재설계**: 일반 정밀도는 전문가가 만든 정답 자료가 있어야 잰다.
- **뷰어·생성기 파일 분리**: 결함이 아니라 구조 정리다. 이번 릴리스의 변경 폭을 키우지 않으려고 미뤘다.
- 한글 파일의 Windows 확인, 미리보기 정화의 자동 시험.
