# 외부 리뷰 지적 반영 (2.3.0)

2026-11-12 외부 리뷰의 지적을 코드에서 확인한 뒤 반영한 것과 남긴 것.

## 반영

- **뷰어 접근 경계**: 서버를 `127.0.0.1` 에만 바인딩. 요청마다 Host(이 컴퓨터 주소·포트)·Origin(같은 주소)·교차 사이트 표시를 검사해 아니면 403. 요청 본문 1 MiB 상한(413). 회귀 시험 `mcp:test:viewer-security`(판정 10건 + 실제 서버 5건, `npm test` 포함).
- **미리보기 HTML 정화**: `marked` 결과를 허용 태그·속성 목록으로 거른다(그 밖의 태그는 글자로 표시, 이벤트 속성과 http(s)·mailto 가 아닌 링크 제거). 실제 브라우저에서 스크립트·이미지 오류 처리기·iframe·`javascript:` 링크가 실행·삽입되지 않고 표·굵은 글씨·체크 상자·코드 블록은 유지되는 것을 확인. 자동 회귀 시험은 없다(브라우저 DOM 필요).
- **문서 머리말**: 필수 항목 미작성 외의 검증 오류도 반영. 통과 시 문구는 "자동 검사 통과 — 담당자 검토와 결재선 서명·날짜 확인이 남아 있습니다".
- **법령 근거 조회 오류**: 검토 규칙·필수 필드가 없는 문서(37종)에서 실패하던 것 수정.
- **README·ARCHITECTURE 지표 이름**, 근거 검증의 범위, 한계(검토 전 연결, HWPX 미지원, 뷰어는 단일 컴퓨터용).

## 남긴 것

- **근거 검증의 판정 정책**: 구조화 근거의 번들 미수록은 "환각"으로, 본문 인용의 번들 미수록은 경고로 처리하는 불일치. 확인됨/번들에 없음/근거 없음으로 나누려면 판정 값과 이를 읽는 쪽이 함께 바뀌어야 해서 정책 결정 후 진행.
- **평가 지표 재설계**: 일반 정밀도·재현율과 전문가 평가. 이번에는 이름과 설명만 고쳤다.
- **한쪽에만 있던 연결의 항목별 검토**(법령 근거 79건, 규율 309건).
- **HWPX 내보내기**, 뷰어 파일 분리, `marked` 를 외부 CDN 에서 불러오는 구조, 법령 판본 점검이 인증키 없으면 건너뛰는 동작.
