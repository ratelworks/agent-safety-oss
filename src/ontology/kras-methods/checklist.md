# 체크리스트법 (checklist)

> **출처**: KOSHA KRAS — `https://portal.kosha.or.kr/kras/evaluation/kras-method` (formId 10183)
> **저작권**: KOSHA 자료 (출처 표시 필수)
> **마지막 동기화**: 2026-04-24

## 핵심 컨셉

평가 대상에 대해 **사전에 준비된 세부 항목 목록**을 사용하여 ○/× 또는 적정/보완/해당없음으로 표기. 표준화된 반복 작업에 효율적.

## 적용 조건

- 동일 유형 작업·설비가 **반복**되는 사업장 (예: 자동차 부품 가공 라인)
- 산업·공정별 표준 체크리스트가 이미 존재하는 경우 (KOSHA Guide 등)
- 신규 설비·작업 도입 시 빠른 위험요인 점검

## ⚠ 주의사항

체크리스트가 **지나치게 단순**하거나 **주관적**으로 작성되면 중요한 유해·위험요인을 놓칠 수 있음.

| 나쁜 예 | 좋은 예 |
|---|---|
| "이 프레스는 위험한가?" (×) | "이 프레스는 작업 시 광전자식 방호장치가 제대로 작동하는가?" (○) |

## 3단계 절차

```
1. 체크리스트 항목 작성    2. 각 항목별 허용 가능       3. 위험성 감소대책
   (또는 표준 체크리스트       수준 여부 판단              안전조치 실시
   채택)                  (적정 / 보완 / 해당없음)
```

## 평가 기록 예시 구조

| 번호 | 유해·위험요인 파악 (체크리스트 항목) | 적정 | 보완 | 해당없음 | 개선대책 | 개선 완료일 | 담당자 |
|:---:|---|:---:|:---:|:---:|---|:---:|---|
| 1 | 프레스에 방호장치(광전자식·양수조작식 등)가 설치되었는가? | ○ |  |  | - | - | 박관리 |
| 2 | 프레스 방호장치는 정상 작동하는가? |  | ○ |  | 광전자 센서 재교정 + 일일 점검표 도입 | 2026-05-10 | 정감독 |
| 3 | 유압 프레스에 안전블럭을 구비했는가? | ○ |  |  | - | - | 박관리 |

## 체크리스트 항목 작성법 (KOSHA 가이드)

각 항목은 다음 4영역으로 구성:
1. **평가대상**: 공정·작업·장소·재해유형 중 분류
2. **유해·위험요인 + 발생형태**: 평가대상에 내재된 안전·보건상 위험요인 도출
3. **위험성 확인결과**: 각 유해·위험요인의 안전·보건조치가 적절한지 확인
4. **개선대책**: 제거 → 대체 → 추가 안전조치 순서로 실행 가능한 대책 수립

## 추천 표준 체크리스트 출처

- **KOSHA Guide**: 공종/설비별 표준 체크리스트 (http://www.kosha.or.kr → 안전보건자료실 → KOSHA Guide)
- **사고사망 게시판**: 동일 유형 사고 사례 기반 체크 항목 보강
- **산안기준규칙 별표**: 법령상 의무 점검 항목 (예: §38 별표 4 — 작업계획서 13종 작업)

## LLM 작성 시 주의

- 체크 항목은 **구체적 행동·상태**로 (예: "안전한가?" 금지)
- "보완" 항목은 반드시 개선대책·기한·담당자 동시 기록
- 체크리스트만으로 부족한 경우 `key_factor` 또는 `frequency_severity` 와 병행
