# 산업보건 위험성평가법 (occupational_health)

> **출처**: KOSHA KRAS — `https://portal.kosha.or.kr/kras/evaluation/kras-method` (formId 10186)
> **저작권**: KOSHA 자료 (출처 표시 필수)
> **마지막 동기화**: 2026-04-24

## 핵심 컨셉

산업보건 활동 수준을 **3대 분야** 의 직업병 유해·위험요인과 발생 가능성(예방조치) 으로 종합 평가하는 체크리스트 기법.

## 적용 조건

- **건강관리·작업환경 영역** 평가 필요
- **직업병** 위험 (소음·분진·근골격계·뇌심혈관·직무스트레스 등)
- 특수건강진단 결과 활용 평가
- 보건관리자 선임 사업장의 자체 진단

## 3대 분야

| 분야 | 평가 항목 |
|---|---|
| **보건관리체계** | 관리인력 선임, 예산 투입, 법규 준수, 보건관리 활동 평가 수립 |
| **작업환경관리** | 환기설비 설치·성능, 유해인자별 관리 설비, 작업환경측정 결과 |
| **건강관리** | 특수건강진단 결과, 잠재 질병위험군 보유, 직무스트레스·뇌심혈관·근골격계 위험 |

## 4단계 절차

```
1. 질병 위험요인 파악      2. 위험요인 관리수준 파악     3. 분야별 취약요인 발굴    4. 개선대책 수립·시행
   - 위험작업 보유현황         - 관리인력 선임            - 위험요인 + 관리수준        - 취약분야 핵심 개선대책
   - 유해인자 노출수준         - 예산 투입                - 파악으로 취약분야 확인
   - 근로형태                 - 환기설비 설치·성능         - 유해인자별 설비·성능
   - 직업병 보유여부           - 법규 준수                                          - 개선이행 상태 확인
```

## 단계별 상세 (KOSHA 가이드)

### ① 질병 위험요인 파악
- 직업병 유발 위험작업 보유 여부 (예: 화학물질 취급, 소음·분진 노출, 중량물 취급)
- 작업환경측정 결과 + 특수건강진단 결과 통한 노출수준 + 건강이상자 확인
- 최근 1년 특수건강진단 결과 → 유소견자/요관찰자 보유현황
- 직무스트레스·뇌심혈관계·근골격계 위험작업·위험군 식별

### ② 위험요인 관리수준 파악
- 보건관리 활동 계획 수립·이행 상태
- 보건관리자 선임 + 예산 편성 + 전문성 향상 지원
- 작업별 개선설비 설치 여부 + 성능
- 작업방법·작업장 구조 특성 + 노출 최소화 추가 대책

### ③ 분야별 취약요인 발굴
- 위험요인 × 관리수준 매트릭스로 취약 분야 도출
- 우선순위: 관리수준 낮음 + 위험요인 높음 = 즉시 개선

### ④ 개선대책 수립·시행
- 핵심 개선대책 → 일정 → 담당자 → 예산
- 개선 이행 상태 정기 확인

## 평가 기록 예시 구조

| 분야 | 평가 항목 | 보유 여부 | 관리수준 | 취약 여부 | 개선대책 |
|---|---|:---:|:---:|:---:|---|
| 보건관리체계 | 보건관리자 선임 | ○ | 적정 | - | - |
| 보건관리체계 | 보건예산 편성 | ○ | 부족 | ⚠ | 예산 30% 증액 |
| 작업환경관리 | 도장공정 환기설비 | ○ | 성능부족 | ⚠ | 흡인풍속 측정 후 보강 |
| 건강관리 | 특수건진 유소견자 (소음) | 3명 | 추적관찰 미흡 | ⚠ | 청력 보호구 + 분기별 청력검사 |

## LLM 작성 시 주의

- 일반 안전(`frequency_severity` 등) 과 **별도 평가** 로 진행
- 작업환경측정 결과는 반드시 **법정 노출기준** 대비 비율로 기록
- 특수건진 결과는 **개인 식별 정보 분리** (집계만)
- 화학물질 분야는 `chemical` 방법과 **연계 평가** 권장

## 관련 KRAS 시스템

- KRAS 보건평가법으로 회원가입 후 작성 가능 (http://kras.kosha.or.kr)
- 작업환경측정·특수건진 결과 자동 연동 (사업장 등록 시)
