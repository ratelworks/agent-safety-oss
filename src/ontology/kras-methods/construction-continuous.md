# 건설업 최초·상시·수시·정기 위험성평가 (construction_continuous)

> **출처**: KOSHA KRAS — `https://portal.kosha.or.kr/kras/evaluation/kras-method` (formId 10188)
> **저작권**: KOSHA 자료 (출처 표시 필수)
> **마지막 동기화**: 2026-04-24

## 핵심 컨셉

건설업 특성(주문생산·옥외·다공종·다업체·재해 빈발)에 맞춘 **상시평가** 중심 체계. 매월 위험요인 파악 + 매주 원·하청 합동안전점검 + 매일 TBM 으로 일상화된 안전활동 이행 시 정기·수시평가를 갈음.

## 적용 대상 (의무)

- **모든 건설현장** (산업안전보건법 §36 + 위험성평가 고시 2024-76호)
- 특히 **120억 미만 중·소규모 건설현장** (최근 3년 사고사망 79.6% 집중)
- 원도급사가 주도, 협력업체 모두 참여

## 평가 종류 4가지

| 종류 | 시기 | 내용 |
|---|---|---|
| **① 최초평가** | 사업장 성립(실착공) 후 1개월 내 | 최초 위험성평가 + 실시규정 작성 + 담당자 지정 |
| **② 정기평가** | 매년 1회 | 최초평가 결과의 적정성 재검토 |
| **③ 수시평가** | 신규 설비·물질 도입 또는 산업재해 발생 시 | 변경된 부분만 즉시 평가 |
| **상시평가** | 월·주·일 상시 | **②+③ 갈음 가능** (일상화된 안전활동 이행 조건) |

## 상시평가 = 월 + 주 + 일 일상화된 안전활동

```
월(月) 1회 이상      주(週)                       일(日)
─────────────────  ─────────────────────────  ──────────────
위험성평가표 작성    원·하청 합동안전점검 회의      작업 전 안전점검회의
+ 위험성평가 회의    (이행확인 + 점검)              (TBM, Tool Box Meeting)
─────────────────  ─────────────────────────  ──────────────
위험요인 파악·등급    이행 상태 확인 +              근로자 공유·교육
+ 감소대책 수립      미흡 사항 즉시 조치
```

## 월 단위 위험성평가 단계 (가장 중요)

### ① 사전준비
- 최초평가에서 작성한 실시규정 토대
- **예정공정표 (최대 1개월 이내)** 로 위험성평가 단위 구분
- 안전보건정보 사전조사 (사고사례, 작업환경, 기상정보 등)

### ② 유해·위험요인 파악
- **사업장 순회점검** (안전보건관계자 + 관리감독자)
- **아차사고 분석** (지난 1개월 발생 분)
- **근로자 제안사항 검토**

### ③ 위험성 결정 (3단계 또는 빈도·강도 등 자유 선택)
- 유해·위험요인 등급 결정
- 개선대책 논의

### ④ 감소대책 수립
- 우선순위에 따른 대책 (제거 → 대체 → 공학적 → 관리적 → PPE)

### ⑤ 공유·기록
- TBM, 교육 등으로 근로자 전파
- 위험성평가표 보존 (3년)

## 주 단위 합동안전점검

- **원·하청 합동** 안전보건관계자 회의 + 점검
- 지난 주 평가 결과 이행 상태 확인
- 미이행 사항 즉시 조치 + 책임 명확화
- 회의록·점검표 보존

## 일 단위 TBM (작업 전 안전점검회의)

- 매일 작업 시작 전 5~15분
- 당일 작업 위험요인 + 어제 평가 결과 + 안전조치 공유
- `get_tbm_schema` Tool 결과와 결합 권장
- 참석자 서명 또는 사진 기록

## 참여자 구성

| 역할 | 책임 |
|---|---|
| **사업주** (원도급사 대표 또는 안전보건관리책임자) | 위험성평가 주도·총괄 관리 |
| **안전보건관계자** (안전관리자, 보건관리자) | 평가 절차 설계·운영 |
| **관리감독자** (직장·조장·반장·팀장) | 작업별 위험요인 파악·조치 |
| **일반 근로자** | 아차사고 보고·제안 |
| **협력업체 관계자** | 자기 작업 위험성평가 + 합동회의 참여 |

## 위험성평가표 표준 양식 (KOSHA 권장)

| 평가일 | 공정/작업 | 유해·위험요인 | 위험성 등급 | 감소대책 | 담당자 | 이행 일정 | 이행 확인 |
|---|---|---|:---:|---|---|---|:---:|

매월 갱신, 변경 시 수시 추가.

## 법적 근거

- **산업안전보건법 §36** — 사업주의 위험성평가 의무
- **산업안전보건법 시행규칙 §37·§38** — 실시 시기, 결과 기록·보존(3년)
- **산업안전보건기준에 관한 규칙 §38** — 사전조사 및 작업계획서 작성
- **고용노동부 고시 제2024-76호** — 사업장 위험성평가에 관한 지침 (시행 2025-01-02)

## LLM 작성 시 주의

- **상시평가** 채택 시 **월·주·일 3개 단위 모두** 이행해야 정기·수시 갈음 효과 발생. 하나라도 빠지면 별도 정기·수시평가 추가 필수
- 매월 위험성평가표 작성 → KRAS 시스템 또는 자체 양식 사용 (양식 자유)
- TBM은 매일 기록 필수 (사진·서명 중 1개) — 감독 시 핵심 증빙
- 협력업체 평가 결과도 원도급이 통합 관리
- 법령 인용은 반드시 `get_safety_law_article` Tool 로 현행본 확인 후 사용

## 관련 Tool 연계

- `get_risk_assessment_schema({method: "construction_continuous"})` → 월 단위 평가표 양식
- `get_tbm_schema` → 일 단위 TBM 일지 양식
- `get_work_plan_schema({workType})` → 산안기준규칙 §38 작업계획서 13종
