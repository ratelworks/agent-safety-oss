# 핵심요인 기술법 (key_factor / OPS, One Point Sheet)

> **출처**: KOSHA KRAS — `https://portal.kosha.or.kr/kras/evaluation/kras-method` (formId 10184)
> **저작권**: KOSHA 자료 (출처 표시 필수)
> **마지막 동기화**: 2026-04-24

## 핵심 컨셉

**핵심 질문 4개에 답변**하는 방식으로 위험성평가를 1페이지(One Point Sheet)에 압축. 영국 산업안전보건청(HSE)·국제노동기구(ILO)가 중·소규모 사업장용으로 안내한 기법.

## 적용 조건

- **간단한 작업** (예: 전등 교체, 부품 교체, 일회성 정비)
- 유해·위험요인이 **소수**이고 명확한 작업
- 빠른 작성·공유 필요 (한 장으로 끝)
- **TBM 직전** 5분 평가에 적합

## 4개 핵심 질문

| 단계 | 질문 |
|:---:|---|
| **파악** | ㉠ 어떤 유해·위험요인이 있는가? |
|  | ㉡ 누가 어떻게 피해를 입는가? |
| **평가·결정** | ㉠ 현재 시행 중인 조치는 무엇인가? |
|  | ㉡ 추가적으로 필요한 조치는 무엇인가? |

## 3단계 절차

```
1. 유해·위험요인 파악       2. 위험성 결정              3. 위험성 감소대책
   ㉠ 어떤 위험요인?          ㉠ 현재 조치는?              안전조치 실시
   ㉡ 누가 어떻게 피해?         ㉡ 추가 조치는?
```

## OPS 기록 예시 구조 (1페이지)

```
■ 작업명: 천장 형광등 교체
■ 작업일: 2026-05-01
■ 작업자: 김전기, 박조수

[㉠ 어떤 유해·위험요인이 있는가?]
- 사다리 사용 → 추락 위험 (3m 높이)
- 형광등 파손 → 베임·감전 위험
- 천장 위 전선 → 감전 위험

[㉡ 누가 어떻게 피해를 입는가?]
- 사다리 작업자: 추락 시 골절·뇌손상 가능
- 보조작업자: 낙하 파편 맞음

[㉠ 현재 시행 중인 조치]
- 사다리 안전점검 완료
- 절연장갑 착용

[㉡ 추가적으로 필요한 조치]
- 작업 전 차단기 OFF (LOTO)
- 안전모 착용
- 사다리 하단 보조자 1명 배치

■ 작성자/책임자 서명: ____________
```

## 적용 범위 (KOSHA 가이드)

- "**업무 중**" = 매일 반복 작업 + 임시·수시 작업 모두 포함
- "**근로자**" = 해당 작업자 + 주변 영향 받는 모든 근로자 (협력업체 포함)
- 빠진 유해·위험요인은 관리할 수 없음 → 파악 단계가 가장 중요

## LLM 작성 시 주의

- 각 질문 답변은 **2~5줄 이내**로 간결하게 (1페이지 원칙)
- 위험요인은 **구체적 발생 시나리오** 로 작성 (예: "추락" 만으로 부족 → "사다리 3m 작업 중 균형 상실 → 추락")
- TBM에서 사용하는 경우 → `get_tbm_schema` 와 결합 가능
- 복잡한 작업·다수 위험요인 → `frequency_severity` 로 전환 권장
