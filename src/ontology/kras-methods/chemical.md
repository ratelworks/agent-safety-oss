# 화학물질 위험성평가 (chemical / CHARM)

> **출처**: KOSHA KRAS — `https://portal.kosha.or.kr/kras/evaluation/kras-method` (formId 10187)
> **저작권**: KOSHA 자료 (출처 표시 필수)
> **마지막 동기화**: 2026-04-24

## 핵심 컨셉

CHARM (Chemical Hazard Risk Management) — 영국 HSE의 **Control Banding** 기법 응용. 화학물질의 **유해성(MSDS, CMR, 노출기준) × 노출량(작업환경측정, 취급량)** 으로 정성 평가하고 관리대책 수립.

## 적용 조건

- 화학물질 취급 사업장 **모두 의무**
- MSDS·작업환경측정·특수건진 결과 보유
- 소규모 사업장도 적용 가능 (Control Banding은 원래 SME 대상 설계)

## 평가 방법 (3가지 추정)

| 방법 | 적용 조건 |
|:---:|---|
| **방법 1** | 작업환경측정 결과 **있음** → 측정값/노출기준 비율로 노출수준 결정 |
| **방법 2-1** | 측정 결과 **없음** + 노출기준 설정 물질 → MSDS·취급량으로 추정 |
| **방법 2-2** | 측정 결과 **없음** + 노출기준 미설정 물질 → CMR 정보·구성성분 함유량으로 추정 |

## 4단계 절차

```
1. 사전준비                  2. 위험요인 관리수준 파악     3. 노출수준(가능성) 결정      4. 위험성 추정·결정·대책
   - 평가 대상 선정 (공정·부서)    - 화학물질 목록화           - 방법1·2·3 우선순위           - 유해성 × 노출 매트릭스
   - 자료 수집:               - 공정·물질·취급량·          - 4단계 등급화                - 관리대책 수립
     MSDS, 작업환경측정,           유소견자·MSDS 보유                                    (제거→대체→공학→관리→PPE)
     특수건진, 취급량 현황          여부
```

## 노출수준 결정 (4단계)

**방법 1**: 작업환경 유소견자 발생 → 노출수준 **4등급(가장 높음)**
**방법 1**: 작업환경측정값 / 노출기준 × 100 → 4단계 분류
- 4등급: 100% 초과
- 3등급: 50~100%
- 2등급: 10~50%
- 1등급: 10% 미만

**방법 2**: MSDS 기반 H 코드 + 취급량(소량/중량/다량) → 4단계 추정

## 유해성 등급

MSDS의 **H 코드** + **CMR 분류** 기반:
| 등급 | 분류 |
|:---:|---|
| 4 | 발암·생식독성·돌연변이성 1A·1B (CMR 1군) |
| 3 | 급성독성·심한 자극·민감화 |
| 2 | 자극성·민감화 (피부) |
| 1 | 경미한 자극 또는 분류 없음 |

## 위험성 매트릭스 (예시)

| 노출 4등급 | 노출 3등급 | 노출 2등급 | 노출 1등급 |
|:---:|:---:|:---:|:---:|
| 유해성 4: **즉시 개선** | 즉시 개선 | 단기 | 중기 |
| 유해성 3: **즉시 개선** | 단기 | 중기 | 일상관리 |
| 유해성 2: 단기 | 중기 | 중기 | 일상관리 |
| 유해성 1: 중기 | 일상관리 | 일상관리 | 일상관리 |

## 위험요인 관리수준 파악 예시

| 공정구분 | 화학물질명 | 제조/사용 | 사용용도 | 월 취급량 | 유소견자 발생 | MSDS 보유 |
|---|---|---|---|---|:---:|:---:|
| 도장공정 | 톨루엔 | 사용 | 희석제 | 50L | 무 | 유 |
| 세척공정 | 메탄올 | 사용 | 부품 세척 | 200L | 무 | 유 |
| 도장공정 | A제품 | 제조 | 제품 | 100kg | 무 | 유 |

## 우선 관리 대상

- **CMR 물질** (발암·생식독성·돌연변이): 무조건 4등급
- **법정 관리대상물질** (산안기준규칙 별표 12): 노출기준 엄격
- **취급금지물질** (산안기준규칙 별표 13): 사용 자체 금지

## LLM 작성 시 주의

- 모든 평가는 **MSDS 의무 비치** 전제 (산안법 §114)
- H 코드 누락 시 평가 불가 → MSDS 갱신 우선
- 작업환경측정 미실시 시 측정 권고 (관련 법: 산안법 §125)
- `occupational_health` 와 **연계 평가** 권장 (특수건진 결과 활용)
- KRAS 시스템: http://kras.kosha.or.kr → CHARM 자동 산출
