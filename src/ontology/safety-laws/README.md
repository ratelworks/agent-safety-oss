# 건설·산업안전 법령 번들

이 디렉터리는 `agent-safety-oss` 가 내장하는 건설·산업안전 관련 법령 원문(Markdown)입니다.

## 저작권·라이선스

- **저작권법 §7 (보호받지 못하는 저작물)**: 법률·명령·고시·훈령은 저작권 보호 대상이 아닙니다.
- 따라서 자유롭게 **복제·배포·수정**할 수 있으며 출처표시 의무도 법적 강제가 없습니다.
- 다만 본 프로젝트는 **법제처 국가법령정보센터** (https://www.law.go.kr) 를 원본 출처로 항상 명시합니다.

## 구조 규약

각 MD 파일은 **조문 단위로 `## §N 제목`** 헤딩을 사용합니다. Tool이 정규식으로 섹션을 추출합니다.

```markdown
# 법령 이름

> 출처 / 링크 / 라이선스 / 마지막 동기화 메타

---

## §N 조문 제목

① ...
② ...

**관련**: 다른 조문 참조
**처벌**: (벌칙 조항인 경우)

---

## §N+1 ...
```

## 갱신

⚠ **현재 상태 (v0.1)**: `npm run sync-safety-laws` 는 **수동 갱신 가이드만 출력** 합니다. 법제처 OpenAPI 기반 자동 fetch·재생성은 v0.2 에서 구현 예정. 현재 MD 파일의 "마지막 동기화" 일자 스탬프만 갱신하려면 `--allow-stamp-only` 플래그 사용.

법령이 개정되면:
1. 각 파일 상단의 portalUrl 에서 최신 원문 확인
2. 해당 MD 파일 수동 편집 (또는 Chrome DevTools MCP 로 법제처 렌더링해 추출)
3. `npm run sync-safety-laws -- --allow-stamp-only` 로 일자 스탬프 갱신
4. 빌드 & 커밋

현재 번들된 조문은 **건설·산업안전 실무에서 자주 인용되는 핵심 조문**을 선별한 것이며, 전체 법령을 포함하지 않습니다. 특정 조문이 필요한데 번들에 없다면 `search_safety_laws` 결과의 `lawPortalUrl` 로 법제처 원문을 직접 확인하세요.

## 책임 고지

이 번들은 법령 참조를 **돕기 위한** 자료이며, 법적 효력을 갖는 권위 있는 출처는 아닙니다. 법적 판단이 필요한 경우 반드시 **법제처 국가법령정보센터 (https://www.law.go.kr)** 의 최신 현행본 또는 변호사 자문을 확인하십시오.
