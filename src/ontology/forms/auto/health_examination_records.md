> **📝 작성 가이드**:
>
> **[검진 일자]**
> - 검진 실시일(YYYY-MM-DD). 일반은 사무직 2년 1회·비사무직 1년 1회. 특수는 시행규칙 별표 22 주기. 배치전 검진은 노출 시작 전.
> - 예시:
>   - 2026-04-15 (1회차 일반·정기)
>   - 2026-04-15 (배치전 — 분진 노출 작업 배치 전 실시)
> - 체크포인트: 주기 미준수 시 과태료 (산안법 §175) / 배치전·수시는 노출 시작·증상 발생 시 즉시 / 단체검진 시 일자별 분산 가능
>
> **[검진 종류 (일반/특수/배치전/수시/임시)]**
> - 산안법 §129(일반)·§130(특수)·§131(임시)·시행규칙 §201(배치전·수시) 5종 중 선택. 유해인자 노출 작업자는 일반+특수 모두 의무.
> - 예시:
>   - 일반 (사무직, §129)
>   - 특수 — 소음 (§130, 별표 22 주기 6개월)
>   - 배치전 — 석면 노출 작업 (시행규칙 §201)
>   - 수시 — 직업병 의심 증상 발생 (§131)
> - 체크포인트: 특수건강진단 누락 시 §175 과태료 / 유해인자별 시행규칙 별표 22 주기 준수 / 복수 노출자는 인자별 모든 검진 항목 포함
>
> **[검진 의료기관·의사]**
> - 고용노동부장관 지정 건강진단기관(시행규칙 §198) 명·소재지·검진의 성명. 지정기관 외 진단 시 결과 무효 + 시행규칙 위반.
> - 예시:
>   - 한국산업안전보건공단 직업건강증진센터 (서울 강남구) — 김의사 (직업환경의학과)
>   - 녹색병원 산업의학과 (서울 중랑구) — 박의사 (산업의학)
> - 체크포인트: 고용노동부 지정기관 (kosha.or.kr 명단 확인) / 검진의 면허·전문과목 확인 / 지정 취소·정지 여부 사전 확인
>
> **[근로자 인적사항·직무]**
> - 재해자/근로자 신상정보 (개인정보 보호 — 외부 공개 시 마스킹). 성명·연령·소속·근무경력·직무 명시.
> - 예시:
>   - 홍길동 (만 42세, 형틀목공, 입사 3년차, ㈜황룡건설 본사)
>   - 김근로 (만 58세, 신호수, 입사 1년차, 도급사 ㈜OO 안전팀)
> - 체크포인트: 개인정보 처리 동의서 별도 / 산재보상보험법 신고 자격 / 외부 공개 시 마스킹 (이니셜·연령대)
>
> **[유해인자 노출 정보]**
> - 특수건강진단 대상자의 노출 유해인자(시행규칙 별표 22). 인자명·CAS·노출 농도(작업환경측정 결과)·노출 기간 명시. 일반 검진은 '해당 없음'.
> - 예시:
>   - 소음 / 평균 92 dB(A) / 5년 / 콘크리트 절단
>   - 결정형 유리규산 (CAS 14808-60-7) / 0.08 mg/m³ (TWA 0.05 초과) / 3년 / 터널 굴착
>   - 해당 없음 (일반건강진단)
> - 체크포인트: 작업환경측정 결과와 노출 농도 일치 / 복수 인자 노출 시 모두 기재 / CMR 물질은 결과 30년 보존 (시행규칙 §241)
>
