## 2. 위험성평가 실시규정 (위험성평가 고시 §19) (위험성평가 고시 제19조 (최초평가 시 작성·지속 관리 — 상시근로자 5인 미만, 건설공사 1억원 미만은 생략 가능) + 제11조제1항)

| 항목 | 내용 |
|---|---|
| 1. 평가의 목적 및 방법 *(필수)* | |
| 2. 평가담당자 및 책임자의 역할 *(필수)* | |
| 3. 평가 시기 *(필수)* | |
| 4. 근로자 및 근로자대표의 참여 방법 *(필수)* | |
| 5. 근로자에 대한 공유 방법 *(필수)* | |
| 6. 결과의 기록·보존 방법 *(필수)* | |
| 위험성 수준 판단 기준과 허용 가능한 위험성 수준 (법령 기준 이상) *(필수)* | |
| 개선대책 고려 순서 | |

> **📝 작성 가이드**:
>
> **[1. 평가의 목적 및 방법]**
> - 평가의 목적과 활용할 기법(고시 §9 — 빈도·강도법, 체크리스트법, 위험성 수준 3단계 판단법, 핵심 요인 기술법 등)과 평가 대상 범위.
> - 예시:
>   - 빈도(1~5) × 강도(1~4) 매트릭스, 위험도 12 이상 우선조치
>   - 전 공정(굴착·골조·마감) + 비정형(긴급보수·청소)
>
> **[2. 평가담당자 및 책임자의 역할]**
> - 실시를 총괄·관리하는 사람(사업주·안전보건관리책임자 등), 관리감독자(요인 파악·개선대책 이행 참여), 안전관리자·보건관리자(기술적 보좌·지도 조언), 기계·설비 전문가 참여(고시 §8).
> - 예시:
>   - 사업주 1, 관리감독자 2, 작업자대표 3, 안전관리자 1
>
> **[3. 평가 시기]**
> - 최초(작업을 시작하기 전까지) · 정기(최초평가 연도의 다음 연도부터 매년 1회 이상) · 수시(관련 작업을 시작하기 전까지) · 상시평가를 택하면 매월·매주·매 작업일 (시행규칙 §37 ②, 고시 §13~§16).
> - 예시:
>   - 최초 착공 전 / 정기 매년 12월 / 수시 공정·장비 변경 시 작업 전 / 상시 매월 둘째 주·매주 월요일·매 작업일 TBM
>
> **[4. 근로자 및 근로자대표의 참여 방법]**
> - 해당 작업에 실제 종사하는 근로자를 요인 파악·위험성 결정·개선대책 수립·이행 후 확인에 참여시키는 방법(사업장 순회 점검 원칙), 근로자대표가 요구할 때의 참여 협의 방법(고시 §6·§7).
> - 예시:
>   - TBM에서 5분 의견청취, 월 1회 협의회
>
> **[5. 근로자에 대한 공유 방법]**
> - 실시 전 일정·실시 후 결과를 알리는 방법 — 안전보건교육·설명회·게시·문서·작업 전 안전점검회의·전자적 방법 중 하나 이상, 신규 채용·작업 변경 근로자는 작업 시작 전 공유(고시 §17).
> - 예시:
>   - 실시 일정: 현장 게시판 + 카카오 알림 / 결과: 정기교육 + 게시 + TBM, 신규 채용자는 채용 시 교육에서 공유
>
> **[6. 결과의 기록·보존 방법]**
> - 기록 항목(실시 시기·담당자·참여 근로자·근로자대표·결과 4가지)과 보존 3년(개선대책 수립 완료 다음 날부터), 전자문서 보존 여부(시행규칙 §37의4, 고시 §21).
> - 예시:
>   - 전자문서(현장 공유 드라이브) + 출력본 사무실 보관, 개선대책 수립 완료 다음 날부터 3년
>
> **[위험성 수준 판단 기준과 허용 가능한 위험성 수준 (법령 기준 이상)]**
> - 위험성을 결정할 때 쓸 판단 기준과 허용 가능한 수준을 미리 정한다(고시 §11 ①). 위험성 결정은 이 기준으로 한다(§11 ②).
> - 예시:
>   - 빈도(1~5)×강도(1~4), 8 이하 허용 가능 / 9~12 개선 후 작업 / 15 이상 작업 중지
>
> **[개선대책 고려 순서]**
> - 제거 → 대체 → 공학적 대책 → 관리적 대책 → 개인보호구 순으로 적용.
> - 예시:
>   - 1순위 제거(공정변경), 2순위 대체(저위험물질), 3순위 공학적(방호장치), 4순위 관리적, 5순위 PPE
>
