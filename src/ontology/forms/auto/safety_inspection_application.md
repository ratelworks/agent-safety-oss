> **📝 작성 가이드**:
>
> **[사용 사업주 회사명·소재지]**
> - 도로명주소 + 건물명·동·층 + 좌표. 공사현장은 공사명·시공구간 명시.
> - 형식: `[도로명주소] [건물명·동·층] (좌표 [위도, 경도])`
> - 예시:
>   - 충남 천안시 동남구 ... 황룡건설 신축현장 1공구 (지하3층 굴착부)
>   - 경기 화성시 ... 봉담휴게소 휴게동 신축공사 (지상15층)
> - 체크포인트: 응급차량 진입 경로 별도 표시 / 현장 입출구 위치 명시 / 주소 변경 시 즉시 갱신
>
> **[검사 대상 사업장]**
> - 법정 점검 주기·항목·결과 처리. 산안법 §93 안전검사·자체점검·정기점검 구분.
> - 형식: `[유형] [주기] / 항목 [N]개 / 결과: 적합/부적합 / 조치: [내용]`
> - 예시:
>   - 일일 자체점검 / 항목 15개 / 적합 14·부적합 1 (안전난간 일부 손상) / 즉시 보수
>   - 정기 안전검사 (산안법 §93) / 분기 1회 / KOSHA 검사기관 / 합격증 부착
> - 체크포인트: 법정 검사 대상 (시행령 §78 11종) / 점검 결과 5년 보존 / 부적합 발견 시 즉시 작업중지
>
> **[대표자·안전관리자]**
> - 전체 이름 + 자격·직위. 자격증 보유자는 자격증 번호 명시 권장.
> - 형식: `[성명] ([직위]·[자격명·번호])`
> - 예시:
>   - 홍길동 (현장소장·건설안전기사 18-XXX)
>   - 김안전 (안전관리자·산업안전기사 19-XXX)
> - 체크포인트: 자격증 사본 비치 / 선임 신고 의무 (산안법 §17~§19) / 겸직 금지 직위 확인
