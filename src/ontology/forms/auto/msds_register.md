## 1. 화학제품과 회사에 관한 정보 (GHS 1 + 산안법 §110 ① 1호)

| 항목 | 내용 |
|---|---|
| 사업장명 *(필수)* | |
| 게시 위치 *(필수)* | |
| 제품명·물질명 *(필수)* | |
| 사용 용도·제한 *(필수)* | |
| 제조·수입자 회사명·주소 *(필수)* | |
| 응급 연락처 (24시간) *(필수)* | |

> **📝 작성 가이드**:
>
> **[사업장명]**
> - MSDS 비치·게시 사업장명.
>
> **[게시 위치]**
> - MSDS 게시 위치 (작업장·휴게실 등).
>
> **[제품명·물질명]**
> - MSDS 1번 항목. 시판 제품명 + 화학물질명 명시. 혼합물은 주성분 강조.
> - 형식: `[제품명] (주성분: [화학명])`
> - 예시:
>   - 신너 600 (주성분: 톨루엔, 자일렌, MEK 혼합)
>   - 에폭시 도료 P-100 (주제: 비스페놀 A 에폭시)
> - 체크포인트: KOSHA MSDS DB(msds.kosha.or.kr)에서 동일 제품 검색 / 제조사 카탈로그 사양과 일치
>
> **[사용 용도·제한]**
> - 용도(도장·접착·세척·반응제 등) + 사용 제한 (실내·실외·환기조건) 명시.
> - 형식: `[용도]. 제한: [환기·온도·금지조건]`
> - 예시:
>   - 페인트 희석용. 제한: 실내 환기 필수, 화기 엄금.
>   - 콘크리트 양생제. 제한: 5°C 이상, 비올 때 사용금지.
> - 체크포인트: 오용 가능성 있는지 / 허가 용도와 실제 사용 일치
>
> **[제조·수입자 회사명·주소]**
> - 제조·수입자 회사명·주소·대표자 명시. 수입품은 한국 대리점 정보 추가.
> - 형식: `[회사명], [주소], 대표 [성명], 사업자등록번호 [N-N-N]`
> - 예시:
>   - ㈜한국케미칼, 경기 화성시 ..., 대표 김OO, 123-45-67890
>   - BASF 한국지사, 서울 ..., 대표 ...
> - 체크포인트: MSDS 작성 책임자 사인 / 사업장 비상연락 가능 여부
>
> **[응급 연락처 (24시간)]**
> - 24시간 응급 전화. 제조사 비상 연락 + 한국독성정보센터 1899-9594 + 119 명시.
> - 형식: `제조사 [N-N-N], 한국독성정보센터 1899-9594, 소방 119`
> - 예시:
>   - ㈜한국케미칼 1588-XXXX (24h), 한국독성정보센터 1899-9594, 119
>   - BASF 24h Hotline +49-180-..., 1899-9594, 119
> - 체크포인트: 24시간 응답 가능 / 한국어 응답 가능
>

## 2. 유해성·위험성 (GHS 2 + 산안법 §110 ① 2호)

| 항목 | 내용 |
|---|---|
| GHS 분류 (급성독성·피부부식·심각한 눈손상 등) *(필수)* | |
| GHS 그림문자 (해골·불꽃·부식 등) *(필수)* | |
| 신호어 (위험·경고) *(필수)* | |
| 유해·위험문구 (H-code) *(필수)* | |
| 예방조치 문구 (P-code) *(필수)* | |

> **📝 작성 가이드**:
>
> **[GHS 분류 (급성독성·피부부식·심각한 눈손상 등)]**
> - GHS(전세계 통일 분류) 기준 위험 분류. 급성독성·피부부식·심각한 눈손상·발암성·생식독성·표적장기독성·흡인독성·인화성·산화성 등.
> - 형식: `[유해성 분류명] 카테고리 [N]`
> - 예시:
>   - 급성독성(경구) 카테고리 4 / 피부 자극성 카테고리 2 / 심각한 눈손상·자극성 카테고리 2A
>   - 인화성 액체 카테고리 2 / 발암성 카테고리 1A
> - 체크포인트: GHS 9차 개정 기준 / Globally Harmonized System UN 권고 / 한국 산안법 §110 별표12·13 기준 일치
>
> **[GHS 그림문자 (해골·불꽃·부식 등)]**
> - GHS 그림문자 9종 중 해당 항목. 해골(독성), 불꽃(인화), 부식(부식성), 환경(수생독성), 가스용기(고압), 폭발물, 산화제, 건강유해성(긴 표적), 느낌표(자극).
> - 형식: `[그림문자명] (해골/불꽃/부식 등) — 코드 GHS[N]`
> - 예시:
>   - 해골(GHS06) + 부식(GHS05) + 건강유해성(GHS08)
>   - 불꽃(GHS02) + 느낌표(GHS07)
> - 체크포인트: 용기·포장에도 동일 그림문자 / 9차 GHS 개정 기준
>
> **[신호어 (위험·경고)]**
> - 위험 또는 경고 둘 중 하나. GHS 분류 카테고리에 따라 자동 결정.
> - 형식: `위험 OR 경고`
> - 예시:
>   - 위험 (인화성 액체 카테고리 1·2 또는 급성독성 카테고리 1·2·3)
>   - 경고 (자극성 카테고리 2 또는 만성 카테고리 2)
> - 체크포인트: GHS 분류 카테고리에 따른 자동 결정 (1·2급 = 위험, 그 외 = 경고)
>
> **[유해·위험문구 (H-code)]**
> - H-code 유해·위험 문구 표준 코드 (H200~H420 범위). 다중 분류는 모두 나열.
> - 형식: `H[NNN] [표준 문구] (필요 시 복수)`
> - 예시:
>   - H225 고인화성 액체 및 증기. H315 피부에 자극을 일으킴. H336 졸음 또는 현기증을 일으킬 수 있음.
>   - H350 암을 일으킬 수 있음. H361 태아 또는 생식능력에 손상을 일으킬 우려가 있음.
> - 체크포인트: UN GHS 9차 개정 H-code 정확 사용 / 복수 유해성 모두 표시
>
> **[예방조치 문구 (P-code)]**
> - P-code 예방조치 문구 (P101~P501 범위). 예방·대응·저장·폐기 4범주 표준 문구.
> - 형식: `P[NNN] [표준 문구] (예방·대응·저장·폐기 4범주)`
> - 예시:
>   - P210 화기 멀리 — P233 용기는 단단히 밀폐 — P302+P352 피부 묻으면 다량의 물·비누로 씻어내시오 — P403+P235 환기 잘되는 곳에 보관·서늘하게 유지
>   - P201 사용 전 특별 지시 받기 — P308+P313 노출 우려 시 의학적 진단을 받으시오
> - 체크포인트: GHS 표준 P-code 정확 사용 / 4 범주(예방·대응·저장·폐기) 모두 명시
>

## 3. 구성성분의 명칭 및 함유량 (GHS 3 + 산안법 §110)

| 항목 | 내용 |
|---|---|
| CAS No.·KE No.·UN No. *(필수)* | |
| 성분명·함유량 (중량%) *(필수)* | |
| 불순물·안정제 (있으면) | |

> **📝 작성 가이드**:
>
> **[CAS No.·KE No.·UN No.]**
> - CAS Registry No. (Chemical Abstracts Service) + KE No. (한국 화학물질 등록번호) + UN No. (운송용) 모두 기재.
> - 형식: `CAS [N-NN-N] / KE [NNNNN] / UN [NNNN]`
> - 예시:
>   - CAS 108-88-3 (톨루엔) / KE-32-345 / UN 1294
>   - CAS 67-56-1 (메탄올) / KE-19-12 / UN 1230
> - 체크포인트: KOSHA MSDS DB CAS 검색 일치 / 수입품은 USA Federal Register 등록 확인
>
> **[성분명·함유량 (중량%)]**
> - 단일물질은 100%, 혼합물은 성분별 함유량 (중량%). 5종 이상 주성분 명시. 영업비밀 시 '영업비밀'로 표시 가능.
> - 형식: `[성분명] CAS [N-N-N]: [N]%`
> - 예시:
>   - 톨루엔 CAS 108-88-3: 60% / 자일렌 CAS 1330-20-7: 30% / MEK CAS 78-93-3: 10%
>   - 비스페놀 A 에폭시 CAS 25068-38-6: 70% / 첨가제 (영업비밀): 30%
> - 체크포인트: 함유량 합계 100% 또는 명확한 범위 / 발암성·생식독성 함유 시 0.1% 이상 표시 의무
>
> **[불순물·안정제 (있으면)]**
> - 1% 미만 불순물·안정제. 안전상 중요한 것만 명시. 없으면 '해당사항 없음'.
> - 형식: `[성분명]: [N]% (역할: 안정제·억제제 등)`
> - 예시:
>   - 메탄올 0.5% (안정제)
>   - 해당사항 없음
> - 체크포인트: 발암성 불순물은 0.1% 이상 표시
>

## 4. 응급조치 요령 (GHS 4)

| 항목 | 내용 |
|---|---|
| 눈 접촉 시 *(필수)* | |
| 피부 접촉 시 *(필수)* | |
| 흡입 시 *(필수)* | |
| 섭취 시 *(필수)* | |
| 의사·응급요원에 전달할 정보 *(필수)* | |

> **📝 작성 가이드**:
>
> **[눈 접촉 시]**
> - 눈 접촉 시 즉시 조치. 일반적: 다량의 물 15분 이상 세척 + 의료기관 후송. 화학별 특수 조치 추가.
> - 형식: `즉시 [N]분 이상 [세척방법]. 콘택트렌즈 [제거 여부]. 의료기관 후송.`
> - 예시:
>   - 즉시 다량의 물로 15분 이상 씻어내시오. 콘택트렌즈 제거 가능하면 제거 후 계속 세척. 즉시 의료기관 후송.
>   - 물 15분 세척 후 0.9% 생리식염수로 추가 세척. 안과 즉시 진료.
> - 체크포인트: 응급 세척 시설 위치 (응급세안기·샤워) / 근로자 사전 교육
>
> **[피부 접촉 시]**
> - 피부 접촉 시 즉시 조치. 오염 의류 즉시 제거 + 비누·다량의 물 세척. 화상·자극 시 의료 후송.
> - 형식: `오염 의류 즉시 제거. [세척방법] [N]분 이상. 자극 [지속 시 조치].`
> - 예시:
>   - 오염 의류·신발 즉시 제거. 비누와 다량의 물로 15분 이상 씻어내시오. 자극 지속 시 의료기관 후송.
>   - 오염 의류 제거. 물·비누 20분 세척 + 화상 발생 시 즉시 119.
> - 체크포인트: 사업장 응급 샤워 시설 / 근로자 사전 교육 / 오염 의류 처리 방법
>
> **[흡입 시]**
> - 흡입 시 조치. 환기 좋은 장소로 이동 + 호흡 곤란 시 산소 공급 + 의료 후송.
> - 형식: `환기 좋은 곳으로 이동. 호흡 [상태] 시 [조치]. 의료 후송.`
> - 예시:
>   - 즉시 환기 좋은 장소로 이동. 호흡 곤란 시 산소 공급. 호흡 정지 시 인공호흡 + 119. 의식 없으면 회복 자세.
>   - 환기 좋은 곳 이동 후 안정 + 산소 공급. 1899-9594 한국독성정보센터 자문.
> - 체크포인트: 인공호흡 자격자 사전 지정 / 산소 공급 장비 비치
>
> **[섭취 시]**
> - 섭취 시 조치. 의식 있을 때만 입 헹구기 + 즉시 의료기관 후송 + 강제 토하게 하지 않기.
> - 형식: `[입 헹굼] [토하기 금지/유도] [의사 진료]`
> - 예시:
>   - 의식 있으면 입 헹구기. 강제로 토하게 하지 마시오. 즉시 119 + 의료기관 후송. MSDS 지참.
>   - 다량의 물 마시기. 토하지 말 것. 한국독성정보센터 1899-9594.
> - 체크포인트: MSDS 사본 의료기관 동행 / 근로자 사전 교육
>
> **[의사·응급요원에 전달할 정보]**
> - 응급요원·의사에 전달할 정보 (제품명·CAS·증상·노출시간 등).
> - 형식: `[제품명·성분]·[노출 경로]·[노출 시간]·[증상]을 의사에 전달.`
> - 예시:
>   - 제품명·CAS·노출량·증상 의사에 전달. MSDS 지참.
>   - 톨루엔 노출 의심. 증상: 두통·현기증·구역. 노출 시간 약 10분.
> - 체크포인트: MSDS 응급세트 동행 / 비상 연락처 사전 등록
>

## 5. 폭발·화재 시 대처방법 (GHS 5)

| 항목 | 내용 |
|---|---|
| 적합한 소화제·금지된 소화제 *(필수)* | |
| 화재·폭발 시 특수 위험성 *(필수)* | |
| 소방관용 보호장비 *(필수)* | |

> **📝 작성 가이드**:
>
> **[적합한 소화제·금지된 소화제]**
> - GHS 5.1. 적합한 소화제 + 금지된 소화제 명시. 화학물질별로 물·CO2·분말·폼 적합성 다름.
> - 형식: `적합: [소화제]. 금지: [금지 소화제 + 사유].`
> - 예시:
>   - 적합: 분말·CO2·폼. 금지: 물 (인화성 액체 — 화재 확산 + 비등 위험).
>   - 적합: 다량의 물·물안개. 금지: 없음.
> - 체크포인트: GHS 5.1 표준 / 화학별 적합 소화제 (KOSHA MSDS DB 확인) / 사업장 비치 소화기와 일치
>
> **[화재·폭발 시 특수 위험성]**
> - GHS 5.2. 화재·폭발 시 특수 위험성. 분해 시 발생 유해가스·폭발 위험·반응성 명시.
> - 형식: `[위험] 발생 가능: [유해가스 종류]. [반응성·폭발 위험].`
> - 예시:
>   - 분해 시 CO·CO2·NOx 발생. 가열 시 증기 폭발 위험. 열·점화원 접촉 회피.
>   - 고온 시 자기반응 가능 (130°C 이상). 분해 가스 (할로겐화물 발생).
> - 체크포인트: GHS 5.2 표준 / 분해 산물 명시 / 온도·압력 임계점
>
> **[소방관용 보호장비]**
> - GHS 5.3. 소방관용 보호장비. 자급식호흡기 (SCBA) + 화학방호복 필수.
> - 형식: `[호흡 보호] + [방호복] + [추가 장비]`
> - 예시:
>   - 자급식 호흡기 (SCBA) + 화학방호복 (Type 3) + 내화 장갑·장화. 풍상에서 진화.
>   - 방진·방독 마스크 (P3 + 정화통 OV) + 일반 방화복. 거리 50m 유지.
> - 체크포인트: IDLH 농도 시 SCBA 의무 / 방호복 등급 (Type 3·4·5·6) / 풍상 위치 진화

>

> - GHS 10.4. 분해 시 발생 유해물질. 화재·고온 시 발생 가스 명시.

> - 형식: `[위치명] (작업장 [N]개소 / 사무실 [N]개소)`
> - 예시:
>   - 페인트 보관창고 출입문 옆 + 도장 작업장 게시판 + 안전관리실. 총 3개소.
>   - 화학물질 보관실 출입문 + 실험실 입구 + 사업장 게시판. 총 3개소.
> - 체크포인트: 취급 장소 5m 이내 게시 / 근로자 항상 볼 수 있는 곳 / 갱신 시 즉시 교체
>
> **[근로자 MSDS 교육 일자·이수자]**
> - 산안법 §115 MSDS 교육 의무. 신규 채용·작업변경·MSDS 변경 시 교육. 교육일·이수자·강사 기록.
> - 형식: `[일자]: [강사] [N]시간 / 이수자 [N]명 (서명부 별첨)`
> - 예시:
>   - 2026-04-15: 김안전(보건관리자) 2시간 / 이수자 12명 (서명부 별첨, 작업장 게시).
>   - 2026-04-28 (신규채용 3명): 박안전관리자 1시간 / 이수자 3명 + 시험 통과.
> - 체크포인트: 연 1회 이상 정기 교육 / 신규·변경 시 즉시 교육 / 이수자 서명부 5년 보존
>
> **[경고표지 부착 (용기·포장 GHS 라벨)]**
> - 용기·포장 GHS 경고표지 (산안법 §114). 그림문자·신호어·H-code·P-code·제품명 표시.
> - 형식: `GHS 라벨: 그림문자 [N]종 + 신호어 + H[NNN] + P[NNN] + 제품명 + 제조사`
> - 예시:
>   - GHS 라벨: 불꽃·해골·느낌표 + '위험' + H225·H315·H336 + P210·P233·P302+P352 + '신너 600' + '㈜한국케미칼'.
>   - GHS 라벨: 부식·건강유해성 + '위험' + H314·H350 + P201·P260·P303+P361+P353 + '에폭시 P-100'.
> - 체크포인트: 100mL 미만 소량 용기는 약식 표지 가능 / 한글 + 영문 병기 권장 / 라벨 손상 시 즉시 교체
