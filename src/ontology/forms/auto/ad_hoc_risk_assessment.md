## 수시 위험성평가 (산업안전보건법 시행규칙 제37조제2항제3호 + 위험성평가 고시 제15조)

| 항목 | 내용 |
|---|---|
| 수시평가 사유 *(필수)* | |
| 위험성평가 실시 시기 (관련 작업을 시작하기 전까지) *(필수)* | |
| 위험성평가 기법 *(필수)* | |
| 중대재해 발생 시 — 사업장 전체 유해·위험 요인에 대한 기존 평가 결과 유효성 재점검 (근로자 참여) | |

> **📝 작성 가이드**:
>
> **[수시평가 사유]**
> - 추가적인 유해·위험 요인이 생기는 사유(고시 §15 ②): 1. 사업장 건설물의 설치·이전·변경 또는 해체 2. 기계·기구, 설비, 원재료 등의 신규 도입 또는 변경 3. 건설물, 기계·기구, 설비 등의 정비 또는 보수(주기적·반복적 작업으로서 이미 위험성평가를 실시한 경우에는 제외) 4. 작업방법 또는 작업절차의 신규 도입 또는 변경 5. 그 밖에 사업주가 필요하다고 판단한 경우 — 또는 중대산업사고·산업재해 발생(§15 ③). 해당 호와 변경 내용(이전·이후)을 적는다.
> - 예시:
>   - 굴착 깊이 5m → 8m로 변경, 흙막이 보강 필요
>
> **[위험성평가 실시 시기 (관련 작업을 시작하기 전까지)]**
> - 수시평가는 관련 작업을 시작하기 전까지 실시한다(시행규칙 §37 ② 3호). 평가 실시일과 관련 작업 시작 예정일을 함께 적는다.
> - 예시:
>   - 평가 2026-04-24 / 변경 작업 시작 2026-04-25
>
> **[위험성평가 기법]**
> - 사업장 규모·특성에 맞춰 활용한 기법 — 빈도·강도법 / 체크리스트법 / 위험성 수준 3단계 판단법 / 핵심 요인 기술(One Point Sheet)법 / 규칙 §50 ① 2호 방법 / 그 밖의 적합한 방법(고시 §9).
>
> **[중대재해 발생 시 — 사업장 전체 유해·위험 요인에 대한 기존 평가 결과 유효성 재점검 (근로자 참여)]**
> - 사업장에서 중대재해가 발생하면 원인 요인에 대한 수시평가와 함께, 근로자를 참여시켜 사업장 전체 유해·위험 요인의 기존 평가 결과 유효성을 다시 점검·확인한다(고시 §15 ③ 단서). 해당 없으면 '해당 없음'.
> - 예시:
>   - 해당 없음
>   - 2026-05-03 전 공정 재점검 — 근로자 14명 순회 점검 참여, 기존 결과 3건 보강
>

## 위험성평가 결과 (산업안전보건법 시행규칙 제37조제1항·제37조의3제2호 + 위험성평가 고시 제10조~제12조)

| 항목 | 내용 |
|---|---|
| 파악한 유해·위험 요인 *(필수)* | |
| 위험성 수준 결정 결과 *(필수)* | |
| 개선대책 수립 내용 *(필수)* | |
| 개선대책 이행 결과 *(필수)* | |

> **📝 작성 가이드**:
>
> **[파악한 유해·위험 요인]**
> - 근로자에게 노출된 것이 확인되었거나 노출될 것이 합리적으로 예상되는 모든 유해·위험 요인을 적는다(시행규칙 §37 ① 1호). 확인한 아차사고를 일으킨 요인도 포함한다(고시 §10 ③).
> - 예시:
>   - 8m 굴착 → 측압 증가 → 흙막이 붕괴 위험
>
> **[위험성 수준 결정 결과]**
> - 요인마다 위험성이 허용 가능한 수준인지 결정한 결과를 적는다. 사업장이 미리 정한 판단 기준과 허용 가능한 수준(법령 기준 이상)으로 결정한다(고시 §11).
>
> **[개선대책 수립 내용]**
> - 허용 불가능한 요인마다 개선대책을 적는다. ① 위험한 작업의 폐지·변경·유해물질 대체·설계 단계 제거 → ② 공학적 대책 → ③ 관리적 대책 → ④ 개인용 보호구 순으로 고려하고(고시 §12 ①), 실행에 시간이 걸리는 중대 위험은 잠정 조치를 함께 적는다(§12 ④).
> - 예시:
>   - 어스앵커 1단 추가 + 계측 빈도 증가 (일1회→2회)
>
> **[개선대책 이행 결과]**
> - 개선대책을 이행한 결과와, 이행 후 위험성이 허용 가능한 수준이 되었는지 확인한 결과를 적는다. 허용 가능한 수준이 되지 못하면 추가 대책을 적는다(고시 §12 ③).
>

## 위험성평가 기록·공유 (산업안전보건법 제36조제2항~제5항 + 시행규칙 제37조의2·제37조의3·제37조의4 + 위험성평가 고시 제6조·제7조·제17조·제21조)

| 항목 | 내용 |
|---|---|
| 담당자 — 위험성평가 실시를 총괄·관리한 사람과 평가 담당자 *(필수)* | |
| 위험성평가에 참여한 근로자와 참여 방법 *(필수)* | |
| 위험성평가에 참여한 근로자대표 (요구가 있으면 참여 — 법 §36 ③) *(필수)* | |
| 실시 전 공유 — 위험성평가 실시 일정을 근로자에게 알린 날짜·방법 *(필수)* | |
| 실시 후 공유 — 위 결과(유해·위험 요인·위험성 수준 결정 결과·개선대책 수립 내용 및 이행 결과)를 알린 날짜·방법 *(필수)* | |
| 기록 보존 (3년) | |

> **📝 작성 가이드**:
>
> **[담당자 — 위험성평가 실시를 총괄·관리한 사람과 평가 담당자]**
> - 기록에는 위험성평가 실시 시기 및 담당자를 적는다(시행규칙 §37의4 ① 1호). 사업장을 실질적으로 총괄·관리하는 사람(사업주·안전보건관리책임자 등)이 총괄하고, 관리감독자가 요인 파악·개선대책 이행에 참여한다(고시 §8).
> - 예시:
>   - 김안전 (안전관리자)
>
> **[위험성평가에 참여한 근로자와 참여 방법]**
> - 해당 작업에 실제 종사하는 근로자를 요인 파악·위험성 결정·개선대책 수립·이행 후 확인 단계에 참여시킨다(고시 §6 ①). 참여 방법은 사업장 순회 점검이 원칙이고, 순회 점검에 참여시킬 수 없는 특별한 사정이 있을 때만 설문조사·면담 등으로 하며 그 사정을 적는다(시행규칙 §37의2). 참여한 근로자 명단을 기록에 남긴다(§37의4 ① 2호).
> - 예시:
>   - 사업장 순회 점검 (2026-09-03, 참여 근로자 8명)
>   - 순회 점검 불가(야간 교대) → 면담 5명 + 설문조사 12명
>
> **[위험성평가에 참여한 근로자대표 (요구가 있으면 참여 — 법 §36 ③)]**
> - 근로자대표가 요구하면 참여시키고 참여 일정·범위·방법을 협의한다(법 §36 ③, 고시 §7). 요구 유무와 참여 결과를 적는다 — 요구가 없었으면 '요구 없음'.
> - 예시:
>   - 근로자대표 참여 요구 있음 → 참여 (김대표, 2026-09-03)
>   - 요구 없음
>
> **[실시 전 공유 — 위험성평가 실시 일정을 근로자에게 알린 날짜·방법]**
> - 위험성평가를 실시하기 전에 실시 일정을 근로자에게 알린다(시행규칙 §37의3 1호). 방법은 안전보건교육·설명회·사업장 게시·문서 전달·작업 전 안전점검회의·전자적 방법 등 하나 이상(고시 §17 ①).
> - 예시:
>   - 2026-09-01 / 현장 게시판 공고 + 작업 전 안전점검회의 구두 공지
>
> **[실시 후 공유 — 위 결과(유해·위험 요인·위험성 수준 결정 결과·개선대책 수립 내용 및 이행 결과)를 알린 날짜·방법]**
> - 실시 후 파악한 유해·위험 요인, 위험성 수준 결정 결과, 개선대책 수립 내용 및 이행 결과를 근로자에게 알린다(시행규칙 §37의3 2호). 신규 채용·작업 변경으로 공유받지 못한 근로자에게는 작업 시작 전에 공유한다(고시 §17 ②).
> - 예시:
>   - 4개 항목 전체를 현장 게시판 게시(2026-09-10) + 정기 안전보건교육 시 설명
>
> **[기록 보존 (3년)]**
> - 기록은 3년간 보존한다(시행규칙 §37의4 ②). 보존 기한은 개선대책 수립을 완료한 다음 날부터 센다(고시 §21 ①). 전자문서로 보존할 수 있다(§21 ②).
>
