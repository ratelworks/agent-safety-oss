> **📝 작성 가이드**:
>
> **[건설재해예방전문지도기관·자격]**
> - 법정 자격(국가기술자격·경력 N년·교육 이수)을 산안법 시행령·시행규칙 별표 기준으로 명시.
> - 형식: `[자격명] (취득 YYYY-MM-DD, 번호 [N-N-N]). 경력 [N]년.`
> - 예시:
>   - 산업안전기사 (2018-XX-XX, 번호 18-09-XXXXX). 건설업 안전관리 5년.
>   - 건설안전기사 + 안전관리실무교육 (KOSHA 24시간 이수, 2026-03)
> - 체크포인트: 산안법 시행령 별표 4 자격 요건 충족 / 교육 이수증 첨부 / 지속교육 의무 (2년 1회)
>
> **[건설공사명·공사규모]**
> - 공식 발주 공사명 + 발주처 + 도급계약번호. 공정·공구·구간 추가.
> - 형식: `[공사명] / 발주: [발주처] / 계약 [번호] / [공정·공구]`
> - 예시:
>   - 천안시청 신청사 신축공사 / 발주: 천안시 / 계약 2026-건설-XXX / 토공 1공구
>   - 한국전력 변전소 증설 / KEPCO / 2026-XXX / 전기공사
> - 체크포인트: 발주처 안전관리비 사용계획 (산안법 §72) / 공사 규모 (공사금액 50억·인원 50인 기준)
>

> **📝 작성 가이드**:
>
> **[발견 위험요인·결함]**
> - KOSHA 24종 재해유형 코드 기반 식별. 작업·장비·환경별 hazard 모두 나열. 빈도·강도 추정.
> - 형식: `[재해유형] (코드 [N]) - [발생조건] / 빈도 [A-E] × 강도 [I-IV]`
> - 예시:
>   - 떨어짐 (코드 1, 단부·개구부 작업) / 빈도 B × 강도 II = 고위험
>   - 끼임 (코드 7, 굴삭기 회전체 인접) / 빈도 C × 강도 I = 고위험
> - 체크포인트: KRAS 7대 방법 중 적합 선택 (예: 빈도·강도법) / 잔존위험 평가 + 추가 통제 / 위험성 등급 매트릭스 (method:risk_matrix_5x4)
>
> **[전월 지적사항 이행 확인]**
> - 형식: `[순서] [직위] [성명] [일자] [서명/확인]`
> - 예시:
>   - 1. 작성 안전관리자 김안전 2026-04-28 (서명) / 2. 검토 현장소장 박감독 2026-04-28 (서명) / 3. 승인 사업주 황룡 2026-04-28 (직인)
>   - 원도급 황룡건설 결재 + 하도급 ㈜OO 결재 병기
> - 체크포인트: 3단계 이상 결재 / 결재일자 순차 / 전자결재 시 시스템 로그 보관
>
