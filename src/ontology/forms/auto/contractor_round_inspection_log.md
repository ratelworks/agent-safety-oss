# 도급 작업장 순회점검 일지 (2일에 1회 이상)

> **법적 근거**: art:산안법:64 · art:산안법시행규칙:80 · art:산안법:175
> 도급인이 자신의 사업장에서 관계수급인의 근로자가 작업할 때 실시하는 작업장 순회점검 일지. 산안법 §64 ① 2호 + 시행규칙 §80 ② 에 따라 건설업은 2일에 1회 이상 실시 의무. 50억 미만 도급 사업장 적용.
> **양식 출처**: 산안법 §64 + 시행규칙 §80 ② — 도급사업 작업장 순회점검 (자체 양식)

> **📝 작성 가이드**:
>
> **[순회점검 일시]**
> - YYYY-MM-DD HH:MM. 건설업은 2일에 1회 이상 — 누락 없이 일자 명시.
> - 예시:
>   - 2026-04-29 14:30 (전일 4/27 점검 후 2일 경과)
>
> **[점검자 성명·직위 (도급인 측)]**
> - 도급인 측 점검자. 안전보건총괄책임자 또는 안전관리자.
> - 예시:
>   - 박감독 (현장소장, 안전보건총괄책임자)
>
> **[도급인 사업장명]**
> - 예시:
>   - 황룡건설(주) — 삼성동 공동주택 신축현장
>
> **[관계수급인 사업장명·작업범위]**
> - 수급인 측 사업장명·담당 공종·근로자 수.
> - 예시:
>   - (주)○○건설 — 토공사·굴착, 근로자 8명
>

## Ⅱ. 점검 결과 (산안법 §64)

| 항목 | 내용 |
|---|---|
| 점검 대상 작업장·구간 *(필수)* | |
| 발견 사항 (불안전 상태·행동) *(필수)* | |
| 개선 요구 사항·기한 *(필수)* | |
| 수급인 조치 사항·이행일자 *(필수)* | |
| 이행 확인자 (도급인) 서명 *(필수)* | |

> **📝 작성 가이드**:
>
> **[점검 대상 작업장·구간]**
> - 순회한 구간·작업장 모두.
> - 예시:
>   - 1공구 굴착부 (지하2층) / 양중점 / 자재 야적장
>
> **[발견 사항 (불안전 상태·행동)]**
> - 사진 가능. 불안전 상태·행동 모두.
> - 예시:
>   - 1) 굴착사면 NW측 토류벽 미설치 (불안전 상태)
>   - 2) 신호수 부재 — 굴삭기 후방 작업자 근접 (불안전 행동)
>
> **[개선 요구 사항·기한]**
> - 구체 행동 + 이행 기한.
> - 예시:
>   - 1) 토류벽 즉시 시공 (4/30 17:00 까지) / 미시공 시 작업중지
>   - 2) 신호수 1명 상주 배치 (즉시)
>
> **[수급인 조치 사항·이행일자]**
> - 수급인 응답 + 이행자 성명·서명.
> - 예시:
>   - 1) 토류벽 H-300 4/30 12:00 시공 완료 — (주)○○건설 김반장 (서명)
>   - 2) 신호수 이작업 14:30부터 상주 — (서명)
>
> **[이행 확인자 (도급인) 서명]**
> - 이행 사실을 도급인이 재확인 후 서명.
> - 예시:
>   - 박감독 (서명) 4/30 17:30
>
