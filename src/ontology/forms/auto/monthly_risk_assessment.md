## 2. 매월 1회 이상 — 근로자 참여 위험성평가 (고시 §16 ① 1호) (위험성평가 고시 제16조제1항제1호 (이행하면 제14조 정기평가를 실시한 것으로 본다))

| 항목 | 내용 |
|---|---|
| 위험성평가 실시 시기 (매월 1회 이상) *(필수)* | |
| 위험성평가 기법 *(필수)* | |
| 사업장 순회 점검 — 해당 작업에 실제 종사하는 근로자 참여 *(필수)* | |

> **📝 작성 가이드**:
>
> **[위험성평가 실시 시기 (매월 1회 이상)]**
> - YYYY-MM (당월 1일 ~ 말일)
> - 예시:
>   - 2026-04 (4/1 ~ 4/30)
>
> **[위험성평가 기법]**
> - 사업장 규모·특성에 맞춰 활용한 기법 — 빈도·강도법 / 체크리스트법 / 위험성 수준 3단계 판단법 / 핵심 요인 기술(One Point Sheet)법 / 규칙 §50 ① 2호 방법 / 그 밖의 적합한 방법(고시 §9).
>
> **[사업장 순회 점검 — 해당 작업에 실제 종사하는 근로자 참여]**
> - 매월 해당 작업에 실제 종사하는 근로자가 참여해(고시 §16 ① 1호·§6) 해당 시점에 합리적으로 예상 가능한 유해·위험 요인을 파악한다. 참여 방법은 사업장 순회 점검이 원칙(시행규칙 §37의2).
> - 예시:
>   - 2026-04-08·15·22·29 4회, 안전관리자 김OO
>
> **[아차사고 — 해당 사고를 일으킨 유해·위험 요인]**
> - 확인한 아차사고를 일으킨 유해·위험 요인은 평가 대상에 포함한다(고시 §10 ③).
> - 예시:
>   - 2건: ① 4/12 비계 자재 낙하 (인근 작업자 회피) ② 4/20 절단 공구 미끄러짐
>
> **[근로자 제안 수렴]**
> - 근로자 제안함·주간 안전회의 등을 통한 위험요인 제안
> - 예시:
>   - 3건: 가설계단 경사 / 자재 적치 통로 / 야간 조도 부족
>

| 논의·공유한 매월 평가 결과 *(필수)* | |

> **📝 작성 가이드**:
>
> **[매주 논의 일시·장소]**
> - 주 1회 이상 정기 회의
> - 예시:
>   - 매주 월요일 09:00 / 현장 안전교육실
>
> **[참석자 — 안전보건관리책임자·안전관리자·보건관리자·관리감독자 등 (도급인은 수급인의 안전·보건 관련 관리자 포함)]**
> - 매주 안전보건관리책임자, 안전관리자, 보건관리자, 관리감독자 등을 중심으로 한다. 법 §63 도급인은 수급인의 안전·보건 관련 관리자 등을 포함한다(고시 §16 ① 2호).
> - 예시:
>   - 안전관리자 김안전 + 보건관리자 이건강 + 관리감독자 박감독 외 3명
>
> **[논의·공유한 매월 평가 결과]**
> - 차주 위험요인·작업방법 수정·결정
> - 예시:
>   - 1) 양중 신호체계 통일 / 2) 외국인 안전교육 / 3) 비계 점검 강화
>
> **[이행상황 점검 결과]**
> - 작업방법 변경·통제수단 도입·작업중지 결정
> - 예시:
>   - 1) 양중 시 무전기 채널 7 통일 / 2) 베트남어 교육 5/8 / 3) 비계 일일 점검
>   - 양호 — 비계 안전난간 1개층 누락 → 즉시 설치 완료
>

## 4. 매 작업일 — 작업 전 안전점검회의 등으로 공유·주지 (고시 §16 ① 3호) (위험성평가 고시 제16조제1항제3호 + 산업안전보건법 제36조제4항 후단 (매 작업일 기록은 daily_tbm 서식))

| 항목 | 내용 |
|---|---|
| 당월 작업일 수 / 작업 전 안전점검회의 실시 횟수 *(필수)* | |
| 평균 참석률 | |
| 자주 공유된 유해·위험 요인 (월간) | |
| 근로자 제안 청취·반영 | |

> **📝 작성 가이드**:
>
> **[당월 작업일 수 / 작업 전 안전점검회의 실시 횟수]**
> - 매 작업일마다 시행규칙 §37의3 제2호 사항(유해·위험 요인, 위험성 수준 결정 결과, 개선대책 수립 내용 및 이행 결과)과 근로자가 준수·주의할 사항을 작업 전 안전점검회의 등으로 공유·주지한다(고시 §16 ① 3호).
> - 예시:
>   - 22일 작업 / 22회 실시 (100%)
>
> **[평균 참석률]**
> - 전체 작업자 대비 TBM 참석률
> - 예시:
>   - 96% (52명 중 평균 50명)
>
> **[자주 공유된 유해·위험 요인 (월간)]**
> - TBM 일지 기록 중 반복 등장 위험요인
> - 예시:
>   - 1) 양중 협착 (8회) / 2) 단부 추락 (6회) / 3) 화기 화재 (4회)
>
> **[근로자 제안 청취·반영]**
> - 근로자의 제안이 있으면 그 의견을 듣고 반영하도록 노력한다(고시 §16 ① 3호).
> - 예시:
>   - 3건 제안 — 야간 조도 보강 반영, 자재 적치 통로 확보 반영, 1건 검토 중
>

> **📝 작성 가이드**:
>
> **[매월 평가에서 파악되지 않은 추가 유해·위험 요인 발생 여부와 수시평가 실시]**
> - 상시평가를 해도 매월 평가에서 파악되지 않은 추가 유해·위험 요인이 생길 우려가 있으면 수시평가를 따로 한다(고시 §16 ②). 해당 없으면 '해당 없음'.

## 위험성평가 결과 (시행규칙 §37 ① · §37의3 제2호) (산업안전보건법 시행규칙 제37조제1항·제37조의3제2호 + 위험성평가 고시 제10조~제12조)

| 항목 | 내용 |
|---|---|
| 파악한 유해·위험 요인 *(필수)* | |
| 위험성 수준 결정 결과 *(필수)* | |
| 개선대책 수립 내용 *(필수)* | |
| 개선대책 이행 결과 *(필수)* | |

> **📝 작성 가이드**:
>
> **[파악한 유해·위험 요인]**
> - 근로자에게 노출된 것이 확인되었거나 노출될 것이 합리적으로 예상되는 모든 유해·위험 요인을 적는다(시행규칙 §37 ① 1호). 확인한 아차사고를 일으킨 요인도 포함한다(고시 §10 ③).
> - 예시:
>   - 1) 추락 (2m 이상 단부) / 2) 협착 (양중 하부) / 3) 화재 (용접 불꽃)
>
> **[위험성 수준 결정 결과]**
> - 요인마다 위험성이 허용 가능한 수준인지 결정한 결과를 적는다. 사업장이 미리 정한 판단 기준과 허용 가능한 수준(법령 기준 이상)으로 결정한다(고시 §11).
> - 예시:
>   - 최고 위험성 16 (작업중지) 1건 / 9~12 (즉시개선) 5건 / 4~8 (허용가능) 22건
>
> **[개선대책 수립 내용]**
> - 허용 불가능한 요인마다 개선대책을 적는다. ① 위험한 작업의 폐지·변경·유해물질 대체·설계 단계 제거 → ② 공학적 대책 → ③ 관리적 대책 → ④ 개인용 보호구 순으로 고려하고(고시 §12 ①), 실행에 시간이 걸리는 중대 위험은 잠정 조치를 함께 적는다(§12 ④).
> - 예시:
>   - 1) 추락 — 안전난간 (공학적) + 안전대 (보호구) / 2) 화재 — 가연물 제거 (제거) + 감시자 (관리적)
>
> **[개선대책 이행 결과]**
> - 개선대책을 이행한 결과와, 이행 후 위험성이 허용 가능한 수준이 되었는지 확인한 결과를 적는다. 허용 가능한 수준이 되지 못하면 추가 대책을 적는다(고시 §12 ③).
> - 예시:
>   - 양호 — 비계 안전난간 1개층 누락 → 즉시 설치 완료
>   - 1 (매우낮음)
>

## 위험성평가 기록·공유 (시행규칙 §37의2~§37의4) (산업안전보건법 제36조제2항~제5항 + 시행규칙 제37조의2·제37조의3·제37조의4 + 위험성평가 고시 제6조·제7조·제17조·제21조)

| 항목 | 내용 |
|---|---|
| 담당자 — 위험성평가 실시를 총괄·관리한 사람과 평가 담당자 *(필수)* | |
| 위험성평가에 참여한 근로자와 참여 방법 *(필수)* | |
| 위험성평가에 참여한 근로자대표 (요구가 있으면 참여 — 법 §36 ③) *(필수)* | |
| 실시 전 공유 — 위험성평가 실시 일정을 근로자에게 알린 날짜·방법 *(필수)* | |
| 실시 후 공유 — 위 결과(유해·위험 요인·위험성 수준 결정 결과·개선대책 수립 내용 및 이행 결과)를 알린 날짜·방법 *(필수)* | |
| 기록 보존 (3년) | |

> **📝 작성 가이드**:
>
> **[담당자 — 위험성평가 실시를 총괄·관리한 사람과 평가 담당자]**
> - 기록에는 위험성평가 실시 시기 및 담당자를 적는다(시행규칙 §37의4 ① 1호). 사업장을 실질적으로 총괄·관리하는 사람(사업주·안전보건관리책임자 등)이 총괄하고, 관리감독자가 요인 파악·개선대책 이행에 참여한다(고시 §8).
> - 예시:
>   - 안전팀장 1, 현장반장 2, 근로자대표 1, 작업조 작업지휘자 3 = 7명
>   - 김안전 (안전관리자)
>
> **[위험성평가에 참여한 근로자와 참여 방법]**
> - 해당 작업에 실제 종사하는 근로자를 요인 파악·위험성 결정·개선대책 수립·이행 후 확인 단계에 참여시킨다(고시 §6 ①). 참여 방법은 사업장 순회 점검이 원칙이고, 순회 점검에 참여시킬 수 없는 특별한 사정이 있을 때만 설문조사·면담 등으로 하며 그 사정을 적는다(시행규칙 §37의2). 참여한 근로자 명단을 기록에 남긴다(§37의4 ① 2호).
> - 예시:
>   - 사업장 순회 점검 (2026-09-03, 참여 근로자 8명)
>   - 순회 점검 불가(야간 교대) → 면담 5명 + 설문조사 12명
>
> **[위험성평가에 참여한 근로자대표 (요구가 있으면 참여 — 법 §36 ③)]**
> - 근로자대표가 요구하면 참여시키고 참여 일정·범위·방법을 협의한다(법 §36 ③, 고시 §7). 요구 유무와 참여 결과를 적는다 — 요구가 없었으면 '요구 없음'.
> - 예시:
>   - 근로자대표 참여 요구 있음 → 참여 (김대표, 2026-09-03)
>   - 요구 없음
>
> **[실시 전 공유 — 위험성평가 실시 일정을 근로자에게 알린 날짜·방법]**
> - 위험성평가를 실시하기 전에 실시 일정을 근로자에게 알린다(시행규칙 §37의3 1호). 방법은 안전보건교육·설명회·사업장 게시·문서 전달·작업 전 안전점검회의·전자적 방법 등 하나 이상(고시 §17 ①).
> - 예시:
>   - 2026-09-01 / 현장 게시판 공고 + 작업 전 안전점검회의 구두 공지
>
> **[실시 후 공유 — 위 결과(유해·위험 요인·위험성 수준 결정 결과·개선대책 수립 내용 및 이행 결과)를 알린 날짜·방법]**
> - 실시 후 파악한 유해·위험 요인, 위험성 수준 결정 결과, 개선대책 수립 내용 및 이행 결과를 근로자에게 알린다(시행규칙 §37의3 2호). 신규 채용·작업 변경으로 공유받지 못한 근로자에게는 작업 시작 전에 공유한다(고시 §17 ②).
> - 예시:
>   - 4개 항목 전체를 현장 게시판 게시(2026-09-10) + 정기 안전보건교육 시 설명
>   - 사업장 게시판 게시 + TBM 시 구두 전달
>
> **[기록 보존 (3년)]**
> - 기록은 3년간 보존한다(시행규칙 §37의4 ②). 보존 기한은 개선대책 수립을 완료한 다음 날부터 센다(고시 §21 ①). 전자문서로 보존할 수 있다(§21 ②).
> - 예시:
>   - 전자문서 (위험성평가 시스템) + 출력본 사무실 캐비닛 / 2029-04까지 (3년)
>
