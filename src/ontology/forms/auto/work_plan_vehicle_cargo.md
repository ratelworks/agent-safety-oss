## 차량계 하역운반기계등 사용 작업계획서 (산안기준규칙 §38 + 별표 4 2호)

| 항목 | 내용 |

> **📝 작성 가이드**:
>
> **[추락·낙하·전도·협착·붕괴 위험 예방대책]**
> - ERIC-PP 위계 (1.제거→2.대체→3.공학→4.관리→5.PPE) 따라 우선순위. 시점·담당자·검증 방법 포함.
> - 예시:
>   - 3.공학적: 흙막이 H-Pile + 변위계 일일 측정 / 시점 굴착 시작 전, 담당 안전관리자 / 변위 ±10mm/일 초과 시 작업중지
>   - 4.관리적: 작업허가제 + TBM 5분 / 매일 작업 전, 작업지휘자 홍길동 / 서명부 비치
> - 체크포인트: ERIC-PP 위계 우선순위 준수 (PPE 최후) / 잔존위험 별도 평가 / 이행 점검 주기 명시
>
> **[운행경로 및 작업방법]**
> - 차량계 하역운반기계등의 운행경로 + 작업방법을 한 항으로 통합 작성 (별표 4 2호 본문 일치).
> - 예시:
>   - 운행경로: 정문 → 야적장 → 1공구 (편도 350m, 회차로 별도) / 작업방법: 후진 입고 → 신호수 유도 하차 → 인력 분배
>   - 운행경로: 자재창고 → 가설도로 → B동 양중점 (200m) / 작업방법: 적재 시 결속 → 5km/h 이하 운행 → 양중점 즉시 하차
> - 체크포인트: 경로상 보행자 동선과 분리 / 신호수 배치 (후진·교차로) / 적재 결속 + 과적 금지 + 운행 속도 제한
>
