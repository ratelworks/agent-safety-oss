> **📝 작성 가이드**:
>
> **[최근 1년간 작업장 또는 작업 공정의 신규 가동 또는 변경 여부]**
> - [ ]없음 / [ ]있음 (년월일).
> - 예시:
>   - [√] 없음
>   - [√] 있음 (2026-02-01 — 도장공정 신설)
>
> **[최근 2회 모든 공정 측정결과]**
> - [ ]2회 연속 초과 / [ ]1회 초과 / [ ]1회 미만 / [ ]2회 연속 미만.
> - 예시:
>   - [√] 2회 연속 미만
>
> **[발암성 물질 노출기준 초과]**
> - [ ]없음 / [ ]있음.
> - 예시:
>   - [√] 없음
>
> **[화학적 인자 노출기준 2배 초과]**
> - [ ]없음 / [ ]있음.
> - 예시:
>   - [√] 없음
>
> **[향후 측정주기]**
> - [ ]3개월 / [ ]6개월 / [ ]1년.
> - 예시:
>   - [√] 6개월 (정상)
>   - [√] 3개월 (초과·발암성·2배 초과 시)
>
> **[향후 측정 예상일]**
> - 형식: `YYYY-MM-DD`
> - 예시:
>   - 2026-10-15
