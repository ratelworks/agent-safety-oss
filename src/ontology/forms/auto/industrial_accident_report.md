> **📝 작성 가이드**:
>
> **[산재관리번호(사업개시번호)]**
> - 근로복지공단 산재보험 가입번호 — 산재관리번호. 일괄적용 사업장은 사업개시번호 함께. 미가입 시 사업자등록번호만 (오른쪽 칸).
> - 형식: `산재관리번호 [9~12자리] / 사업개시번호 [4자리]`
> - 예시:
>   - 12345678901 / 0001 (일괄적용 건설업)
>   - (미가입) — 사업자등록번호만
> - 체크포인트: 근로복지공단 발급 정확 확인 / 고용보험번호와 혼동 금지 / 일괄적용은 사업개시번호 누락 X
>
> **[사업자등록번호]**
> - 국세청 사업자등록번호 (10자리, 하이픈 포함 가능).
> - 형식: `XXX-XX-XXXXX`
> - 예시:
>   - 123-45-67890
> - 체크포인트: 10자리 정확 / 사업자 명의 확인
>
> **[사업장명]**
> - 재해자가 사업주와 근로계약을 체결한 사업장명. 파견근로자는 실제 지휘·명령을 받는 사용사업주 사업장명. 하수급 근로자는 하수급 사업장명.
> - 형식: `[사업장명]`
> - 예시:
>   - 황룡건설(주)
>   - (주)○○ — 하수급 (원수급은 ⑦에 별도)
> - 체크포인트: 근로계약 체결 사업장 확인 / 파견·도급 관계 정확 분리 / 본사·현장 구분
>
> **[근로자 수]**
> - 사업장 최근 근로자 수 (정규직·일용직·임시직·훈련생 모두 포함).
> - 형식: `[총인원] 명 (정규 N / 일용·임시 N / 훈련생 N)`
> - 예시:
>   - 85명 (정규 30 / 일용 50 / 훈련생 5)
>   - 120명
> - 체크포인트: 재해발생 당시 기준 인원 / 도급 근로자 별도 계산 / 외국인·파견 포함
>
> **[업종]**
> - 통계청 KSIC 세세분류 5자리. 모를 경우 업종명+주요 생산품 추가.
> - 형식: `[5자리 코드] [업종명]`
> - 예시:
>   - 41210 아파트 건설업
>   - 42110 도로 건설업
>   - (코드 모름) 시멘트제조업 — 시멘트
> - 체크포인트: KSIC 세세분류 정확 / 통계청 사이트(kostat.go.kr) 검색 / 주된 사업 활동 기준
>
> **[소재지]**
> - 재해자 소속 사업장 소재지. 도로명 주소 + 우편번호.
> - 형식: `(우편번호) 도로명 주소`
> - 예시:
>   - (06236) 서울 강남구 테헤란로 123, 황룡빌딩 5층
>   - (18564) 경기 화성시 봉담읍 ... 신축현장
> - 체크포인트: 도로명 주소 사용 / 우편번호 정확 / 본사·현장 구분 명시
>

## Ⅰ-2. 건설업만 작성 (별지 30호서식 Ⅰ — 건설업 한정)

| 항목 | 내용 |
|---|---|
| 발주자 | |
| 원수급 사업장명 | |

| 공사현장 명 | |
| 공사종류 | |
| 공정률 | |
| 공사금액 백만원 | |

> **📝 작성 가이드**:
>
> **[발주자]**
> - 발주자 분류 체크. 민간 / 국가·지방자치단체 / 공공기관 중 1개.
> - 형식: `[ ]민간 [ ]국가·지방자치단체 [ ]공공기관`
> - 예시:
>   - [√] 민간 — 황룡개발(주)
>   - [√] 국가·지방자치단체 — 서울시
> - 체크포인트: 공공기관 = 공공기관운영법상 기관 / 민간 발주는 회사명 병기
>
> **[원수급 사업장명]**
> - 재해자가 하수급 사업장 소속인 경우만 작성. 원수급(원청) 사업장명.
> - 형식: `[원수급 사업장명]`
> - 예시:
>   - (주)황룡건설
> - 체크포인트: 원·하도급 관계 정확 / 재해자 소속이 원수급이면 빈칸
>
> **[원수급 사업장 산재관리번호(사업개시번호)]**
> - 원수급 사업장의 산재관리번호. 일괄적용이면 사업개시번호 함께.
> - 형식: `[산재관리번호] / [사업개시번호]`
> - 예시:
>   - 11111222223 / 0007
> - 체크포인트: 원수급 산재관리번호 정확 / 일괄적용 사업개시번호 누락 X
>
> **[공사현장 명]**
> - 공사명 + 위치 + 공구·구간.
> - 형식: `[공사명] ([위치], [공구])`
> - 예시:
>   - 삼성동 공동주택 신축공사 (서울 강남구, 1공구)
>   - ○○고속도로 ○구간 토공사
> - 체크포인트: 원수급 사업장 기준 공사현황 (단위공사 X) / 공구·구간 명시
>
> **[공사종류]**
> - 재해 당시 진행 중인 공사 종류. 원수급 사업장 공사 현황 기준.
> - 형식: `[공사종류]`
> - 예시:
>   - 아파트
>   - 도로
>   - 댐
>   - 플랜트시설
>   - 전기공사
> - 체크포인트: 원수급 기준 (단위공사 X) / 복합공사 시 주된 공사
>
> **[공정률]**
> - 재해 당시 건설현장 공사 진척도. 전체 공정률 (단위공정률 X).
> - 형식: `[N] %`
> - 예시:
>   - 45
>   - 78
> - 체크포인트: 전체 공정률 (재해 발생 단위공정 X) / 0~100 정수
>
> **[공사금액 백만원]**
> - 원수급 사업장의 공사금액. 백만원 단위.
> - 형식: `[N] 백만원`
> - 예시:
>   - 4500 (45억)
>   - 12500 (125억)
> - 체크포인트: 원수급 기준 / 백만원 단위 (억 단위 X) / VAT 포함 여부 일관
>

| 국적 *(필수)* | |
| 체류자격 | |
| 직업 *(필수)* | |

| 같은 종류업무 근속기간 *(필수)* | |
| 고용형태 *(필수)* | |
| 근무형태 *(필수)* | |
| 상해종류(질병명) *(필수)* | |
| 상해부위(질병부위) *(필수)* | |
| 휴업예상일수 *(필수)* | |
| 사망 여부 *(필수)* | |

> **📝 작성 가이드**:
>
> **[성명]**
> - 재해자 성명. 외국인은 한글표기+로마자병기 권장.
> - 형식: `[성명]`
> - 예시:
>   - 홍길동
>   - Nguyen Van A (응웬반아)
> - 체크포인트: 주민등록상 성명 / 외국인 로마자 병기
>
> **[주민등록번호(외국인등록번호)]**
> - 주민등록번호 13자리. 외국인은 외국인등록번호.
> - 형식: `XXXXXX-XXXXXXX`
> - 예시:
>   - 830101-1234567
> - 체크포인트: 13자리 정확 / 외국인등록번호 가능 / 개인정보 보호 — 작성 후 마스킹·결재본 별도
>
> **[성별]**
> - [ ] 남 [ ] 여 중 1개 체크.
> - 형식: `[ ] 남 [ ] 여`
> - 예시:
>   - [√] 남
>   - [√] 여
> - 체크포인트: 주민번호 7번째 자리와 일치
>
> **[국적]**
> - 내국인/외국인 체크. 외국인은 국적+체류자격(출입국관리법 시행령 별표 1 기호) 작성.
> - 형식: `[ ] 내국인 / [ ] 외국인 [국적: ___ ⑩체류자격: ___]`
> - 예시:
>   - [√] 내국인
>   - [√] 외국인 [국적: 베트남 / 체류자격: E-9]
> - 체크포인트: 체류자격 기호 (E-1, E-7, E-9 등) / 출입국 시행령 별표 1 참조
>
> **[체류자격]**
> - 출입국관리법 시행령 별표 1 기호 (E-1, E-7, E-9 등). 별지 30호서식 ⑩.
> - 예시:
>   - E-9 (비전문취업)
>   - E-7 (특정활동)
>   - F-4 (재외동포)
>
> **[직업]**
> - 통계청 한국표준직업분류 세세분류 5자리. 모를 경우 직업명+주요 업무내용·직위.
> - 형식: `[5자리 코드] [직업명]`
> - 예시:
>   - 철근공
>   - 미장공
>   - 프레스조작원
>   - 토목감리기술자
> - 체크포인트: 통계청 KSCO 세세분류 정확 / kostat.go.kr 검색 / 재해자가 평소 수행 업무 기준
>
> **[입사일]**
> - 재해자가 현 사업장에 입사한 일자.
> - 형식: `YYYY-MM-DD`
> - 예시:
>   - 2024-03-15
> - 체크포인트: 근로계약서 기준 / 수습 시작일이 아닌 정식 입사일
>
> **[같은 종류업무 근속기간]**
> - 과거 다른 회사 경력 + 현직 경력 합산. 동일·유사 업무 근무기간. 질병의 경우 관련 작업 근무기간.
> - 형식: `[N년 N월]`
> - 예시:
>   - 8년 3월 (前 회사 5년 + 현직 3년 3월)
>   - 1년 2월
> - 체크포인트: 동종업무 경력만 합산 / 현 사업장 경력만 X — 전체 동종 경력 / 질병은 관련 작업 노출 기간
>
> **[고용형태]**
> - [ ] 상용 [ ] 임시 [ ] 일용 [ ] 무급가족종사자 [ ] 자영업자 [ ] 그 밖의 사항. 상용=계약기간 1년 이상, 임시=1개월~1년, 일용=1개월 미만 또는 일급제.
> - 형식: `[ ] 상용 [ ] 임시 [ ] 일용 [ ] 무급가족종사자 [ ] 자영업자 [ ] 그 밖의 사항 [___]`
> - 예시:
>   - [√] 일용
>   - [√] 그 밖의 사항 [교육·훈련생]
