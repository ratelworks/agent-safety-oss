## 잠재위험요인 + 대책 (KOSHA 양식 — 잠재위험요인 1~3 / 대책 (제거→대체→통제 순서))

|---|---|
| ❶ 잠재위험요인 *(필수)* | |
| ❶ 대책 (제거→대체→통제 순서) *(필수)* | |
| ❷ 잠재위험요인 | |
| ❷ 대책 | |
| ❸ 잠재위험요인 | |
| ❸ 대책 | |

> **📝 작성 가이드**:
>
> **[❶ 잠재위험요인]**
> - 예시:
>   - 굴착사면 4.5m 토류벽 미설치 → 무너짐
>
> **[❶ 대책 (제거→대체→통제 순서)]**
> - 예시:
>   - 1:1.0 안전기울기 확보 후 진입 + 토류벽 미시공 구간 출입금지 (제거)
>
> **[❷ 잠재위험요인]**
> - 예시:
>   - 굴삭기 후방 사각지대 작업자 접근 → 깔림
>
> **[❷ 대책]**
> - 예시:
>   - 굴삭기 후방 5m 라바콘 + 신호수 1명 상주 (관리적)
>
> **[❸ 잠재위험요인]**
> - 예시:
>   - 매설 가스배관 GL-1.2m 손상 → 가스누출
>
> **[❸ 대책]**
> - 예시:
>   - 매설관 ±30cm 인력굴착 + 도시가스공사 1544-4500 입회 (공학적)
>

## 중점위험요인 (KOSHA 양식 — 잠재위험요인 1~3 중 1개 선정)

| 항목 | 내용 |
|---|---|
| 선정 *(필수)* | |
| 중점위험요인 대책 *(필수)* | |

> **📝 작성 가이드**:
>
> **[선정]**
> - 잠재위험요인 1~3 중 가장 중요한 1개 선정 (보통 가장 위험한 것).
> - 예시:
>   - ❶ 굴착사면 4.5m 토류벽 미설치 → 무너짐
>
> **[중점위험요인 대책]**
> - 선정된 위험에 대한 핵심 대책. 지적확인 사항.
> - 예시:
>   - 1:1.0 안전기울기 + 토류벽 시공 — 지적확인 '안전기울기 확보 한다!'
>

>   - 신호수 배치로 굴삭기 사각지대 사고 0건 — 효과 있음
