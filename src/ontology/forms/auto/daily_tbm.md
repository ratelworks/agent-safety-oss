## 2. TBM — 매 작업일 작업 전 안전점검회의 (위험성평가 고시 제16조제1항제3호 + 산업안전보건법 제36조제4항 후단 + 시행규칙 제37조의3제2호)

| 항목 | 내용 |
|---|---|
| TBM 일시 (작업 시작 전) *(필수)* | |
| 진행자 (관리감독자) *(필수)* | |
| 오늘의 작업 (작업·위치·인원) *(필수)* | |
| 파악한 유해·위험 요인 (오늘 작업) *(필수)* | |
| 위험성 수준 결정 결과 *(필수)* | |
| 개선대책 수립 내용 및 이행 결과 (작업 시작 전 확인) *(필수)* | |
| 근로자가 준수하여야 할 사항 및 주의하여야 할 사항 *(필수)* | |
| 근로자 제안·의견과 반영 | |
| 참석자 명단·서명 *(필수)* | |

> **📝 작성 가이드**:
>
> **[TBM 일시 (작업 시작 전)]**
> - 매 작업일 시작 전.
> - 예시:
>   - 2026-04-29 07:30
>
> **[진행자 (관리감독자)]**
> - 관리감독자 또는 작업지휘자.
> - 예시:
>   - 박감독
>
> **[오늘의 작업 (작업·위치·인원)]**
> - 오늘 시행할 작업·위치·인원.
> - 예시:
>   - A동 6층 외벽 도장 + B동 굴착, 작업자 12명
>
> **[파악한 유해·위험 요인 (오늘 작업)]**
> - 오늘 작업의 유해·위험 요인 — 중대재해로 이어질 수 있는 요인은 반드시 공유한다(법 §36 ④ 후단).
>
> **[위험성 수준 결정 결과]**
> - 요인마다 위험성평가에서 결정한 위험성 수준(허용 가능/불가)을 알린다.
> - 예시:
>   - 개구부 추락 — 허용 불가(개선 후 작업) / 자재 낙하 — 허용 가능(현 대책 유지)
>
> **[개선대책 수립 내용 및 이행 결과 (작업 시작 전 확인)]**
> - 요인마다 개선대책과 오늘 작업 시작 전 이행 여부를 확인해 알린다.
>
> **[근로자가 준수하여야 할 사항 및 주의하여야 할 사항]**
> - 한 가지 핵심 수칙.
> - 예시:
>   - 100% Tie-off 원칙 (안전대 후크 절대 분리 금지)
>
> **[근로자 제안·의견과 반영]**
> - 근로자의 제안이 있으면 그 의견을 듣고 반영하도록 노력한다(고시 §16 ① 3호).
> - 예시:
>   - 작업자 제안: 개구부 덮개 고정 방식 변경 → 오늘 오전 중 조치
>
> **[참석자 명단·서명]**
> - 전원 자필 서명 (외국인 모국어).
>
