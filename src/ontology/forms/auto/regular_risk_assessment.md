## 2. 정기 위험성평가 (연 1회) (위험성평가 고시 제15조 ④ 2호)

| 항목 | 내용 |
|---|---|
| 평가 기간 *(필수)* | |
| 전년도 평가 검토 *(필수)* | |
| 신규 식별 위험요인 *(필수)* | |
| 감소대책 갱신 *(필수)* | |

> **📝 작성 가이드**:
>
> **[평가 기간]**
> - 연 1회 정기.
> - 예시:
>   - 2026-12-01 ~ 2026-12-15
>
> **[전년도 평가 검토]**
> - 전년도 위험요인 + 사고 이력 검토.
> - 예시:
>   - 전년도 식별 15건 → 12건 감소대책 완료, 3건 후속 조치
>
> **[신규 식별 위험요인]**
> - 공정·환경·기술 변화로 신규 발생.
> - 예시:
>   - 타워크레인 신규 도입 → 양중작업 위험요인 5건 추가
>
> **[감소대책 갱신]**
> - 신규+기존 모두 통합.
> - 예시:
>   - 신규 5건 + 갱신 3건 = 8건 추가 대책
>

## 3. 평가 범위 / 방법 / 참여자 (위험성평가 고시 제5조의2·제6조·제7조)

| 항목 | 내용 |
|---|---|
| 평가 범위 *(필수)* | |
| 평가 방법 *(필수)* | |
| 평가 참여자 *(필수)* | |
| 근로자대표 참여 확인 *(필수)* | |

> **📝 작성 가이드**:
>
> **[평가 범위]**
> - 이번 정기평가에 포함한 공정·작업·장소를 구체적으로 작성.
> - 예시:
>   - 토공, 골조, 비계, 도장, 양중 작업 전 공정
> - 체크포인트: 사업장 전체 또는 현장 전체 범위가 누락되지 않았는지 확인
>
> **[평가 방법]**
> - KRAS 7방법 중 실제 적용한 방법과 위험도 판정 기준.
> - 예시:
>   - KRAS 5x4 matrix. 위험도 12 이상 즉시개선, 8~11은 7일 내 개선
> - 체크포인트: 빈도·강도 또는 체크리스트 등 판단 기준 명시
>
> **[평가 참여자]**
> - 사업주 또는 현장소장, 안전관리자, 관리감독자, 근로자대표 참여자.
> - 예시:
>   - 김안전, 이소장, 박반장, 근로자대표 정근로
> - 체크포인트: 근로자 참여 확인
>
> **[근로자대표 참여 확인]**
> - 근로자대표 성명과 서명 여부.
> - 예시:
>   - 정근로 (근로자대표, 서명)
> - 체크포인트: 위험성평가 고시 제6조 참여 원칙
>

## 근로자 공유·기록 (2026-08-01 시행 개정) (산안법 §36 ②·③·④·⑤ + 시행규칙 §37의2·§37의3·§37의4)

| 항목 | 내용 |
|---|---|
| 실시 전 일정 고지일·방법 *(필수)* | |
| 근로자 참여 방법 *(필수)* | |
| 근로자대표 참여 여부 *(필수)* | |
| 실시 후 공유 내용·방법 *(필수)* | |
| 기록 — 실시 시기·담당자·참여자 *(필수)* | |

> **📝 작성 가이드**:
>
> **[실시 전 일정 고지일·방법]**
> - 위험성평가를 실시하기 전에 실시 일정을 근로자에게 알린 날짜와 방법. 사전 고지가 없으면 위반입니다 (시행규칙 §37의3 1호, 신설).
> - 예시:
>   - 2026-09-01 / 현장 게시판 공고 + 작업 전 안전점검회의 구두 공지
> - 체크포인트: 평가 실시일보다 앞선 날짜인지 확인 / 고지 방법을 구체적으로 기재
>
> **[근로자 참여 방법]**
> - 사업장 순회 점검이 원칙입니다. 순회 점검에 참여시킬 수 없는 특별한 사정이 있을 때만 설문조사·면담 등으로 대체하고 그 사유를 적습니다 (시행규칙 §37의2).
> - 예시:
>   - 사업장 순회 점검 (2026-09-03, 참여 근로자 8명)
>   - 순회 점검 불가(야간 교대) → 면담 5명 + 설문조사 12명
> - 체크포인트: 순회 점검 외 방법만 쓴 경우 사유 기재 필수
>
> **[근로자대표 참여 여부]**
> - 근로자대표가 참여를 요구하면 반드시 참여시켜야 합니다 (법 §36 ③, 신설). 요구 유무와 참여 결과를 적습니다.
> - 예시:
>   - 근로자대표 참여 요구 있음 → 참여 (김대표, 2026-09-03)
>   - 요구 없음
>
> **[실시 후 공유 내용·방법]**
> - ① 파악한 유해·위험 요인 ② 위험성 수준 결정 결과 ③ 개선대책 수립 내용 ④ 개선대책 이행 결과 — 4개 항목을 모두 공유해야 합니다. 공유 방법은 안전보건교육·설명회·사업장 게시·서면 또는 전자적 방법 등 (법 §36 ④, 시행규칙 §37의3 2호).
> - 예시:
>   - 4개 항목 전체를 현장 게시판 게시(2026-09-10) + 정기 안전보건교육 시 설명
> - 체크포인트: 4개 항목 중 누락 없는지 확인 / 이행 결과는 조치 완료 후 추가 공유
>
> **[기록 — 실시 시기·담당자·참여자]**
> - 기록에 ① 실시 시기 및 담당자 ② 참여한 근로자 및 근로자대표 ③ 공유 4개 항목이 포함되어야 합니다 (시행규칙 §37의4 ①). 참여 근로자 기록은 신설 항목입니다.
> - 예시:
>   - 실시 2026-09-03 / 담당 김안전(안전관리자) / 참여 근로자 8명 명단 별첨 / 근로자대표 김대표
> - 체크포인트: 참여 근로자 명단 누락 시 과태료 대상 (법 §175 ⑥ 2호의2)
>
